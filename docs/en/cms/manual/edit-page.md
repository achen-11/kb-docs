# Edit a Page Visually

Change text and images on the live page. Click an element to open its menu. After you confirm the text and the image, save from the toolbar on the right. That writes the changes back to the page.

## Open the page

Open **Pages**, then click the pencil icon at the right end of the row.

<ManualImage
  src="/cms/manual/edit-page/pages.jpg"

## Select the text

Click the text (do not double-click or right-click), then click **Edit**.

<ManualImage
  src="/cms/manual/edit-page/select-text.jpg"
  alt="Select the heading and click Edit"
  :marks="[{ x: 35.6, y: 43.5, w: 13.1, h: 6.5, label: '1' }]"
/>

## Edit and confirm

Type in place. Click the check mark on the toolbar to confirm that text.

<ManualImage
  src="/cms/manual/edit-page/edit-text.jpg"

## Replace an image

Click the image, then click **Image**. Check the file you want, then click **Choose**. Clicking the thumbnail alone does not select it.

<ManualImage
  src="/cms/manual/edit-page/choose-image.jpg"
  alt="Check the image and click Choose"

    { x: 71.7, y: 85.5, w: 13.4, h: 7.5, label: '2' }

/>

## Set alternative text

Fill in the alternative text and click **Save**. If the page already has a style for the image, the width and height here do not change how it looks.

<ManualImage
  src="/cms/manual/edit-page/image-settings.jpg"
  alt="Enter the alternative text and save the image settings"
  :marks="[
    { x: 57.5, y: 70.6, w: 25.0, h: 8.4, label: '1' },
    { x: 69.5, y: 84.0, w: 13.4, h: 7.5, label: '2' }
  ]"
/>

## Save the page

Confirming the text or the image only keeps the change in the editor. Click the save icon at the bottom of the toolbar on the right. The number on the undo icon is how many changes are still unsaved.
