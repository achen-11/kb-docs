# Edit a Page Visually

Open the live page preview in site admin, then click elements to change copy and images without editing HTML first.

English screenshots for later steps are not available yet; the steps below match the verified Chinese UI flow. Only the Pages entry screenshot is included here.

## Open visual editing

Go to **Pages**, find the target row, and click the pencil icon on the right.

<ManualImage
  src="/cms/manual/edit-page/pages.jpg"
  alt="Click the pencil icon on the Pages list to open visual editing"
/>

## Select text

**Click** a heading or other text on the preview canvas (do not double-click or right-click). When the menu appears, choose **Edit**.

## Edit and confirm

Type the new copy in place, then click the checkmark on the left of the text toolbar to confirm.

## Choose a replacement image

Click the image → **Image** in the menu to open settings, then click the preview or **Click to replace** to open the media library. Check the checkbox on the file card, then click **Select** (clicking the thumbnail alone does not select it).

## Set alt text and save image settings

In image settings you can review src, width, height, and alt. Enter the description, then click **Save**. If the element already has CSS, width and height may be overridden by styles.
