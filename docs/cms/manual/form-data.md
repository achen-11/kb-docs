# 表单数据管理

页面上的表单提交后，数据一般存在后台的 **数据库 → IndexedDB 表**（或 **数据库 → SQLite 表**）。

<!-- TODO: screenshots pending under /workspace/kb-docs-shots/form-data/ → bake to docs/public/cms/manual/form-data/*.jpg -->

## 打开数据库表

打开 **数据库 → IndexedDB 表**（或 **数据库 → SQLite 表**）。点表名进入该表的数据列表。

## 查看提交记录

进入表后，可浏览各条提交；需要时可编辑或勾选后删除。

## 显示数据库菜单

若左侧没有 **数据库**：点左下角 **编辑菜单**，勾选需要显示的菜单即可。
