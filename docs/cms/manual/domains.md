# 域名管理

每个 Kooboo 账号自带免费域名，适合网站未上线时先测试。正式上线通常要另购域名，再绑定到站点。

## 国内与境外怎么买

- **国内站点**需要备案。Kooboo 不支持备案，建议到 **阿里云** 购买域名，配好解析后再添加到 Kooboo。
- **境外站点**不用备案，可直接在 Kooboo 购买。

## 在 Kooboo 购买域名

入口在控制台 **域名** 页的 **域名购买**（或同页其它购买入口）。

1. 搜索目标域名；未被注册时可点 **注册**。
2. 选择购买年限。联系方式可填可不填；不填则选自动。
3. 点 **确定**，会进入支付页。

本文止于进入支付页；实际付款请在后台自行完成。购买成功的域名会出现在域名列表，之后即可绑定网站。

## 其他平台购买后接入

1. 登录域名服务商（如阿里云）的 DNS 管理，添加两条 **CNAME**：
   - 主机记录 `@`：解析根域名（如 `example.com`）
   - 主机记录 `*`：解析子域名（如 `www.example.com`）
2. 记录值填 Kooboo 服务器域名。在控制台 **域名 → 新建** 弹窗里可以看到该值。
3. 若服务商（如 GoDaddy）不支持根域名直接加 CNAME，可用其域名转发，把根域名转到例如 `www.example.com`。
4. 回到 Kooboo：**控制台 → 域名 → 新建域名**，填入已配好 CNAME 的域名。之后即可绑定网站。

## 给网站绑定或更换域名

打开 **站点设置 → 域名管理**。

- 去掉旧域名：勾选不需要的域名，再删除。刚配完 CNAME 时，因 DNS 缓存，需等 TTL 过后再访问。
- 绑定新域名：点 **新建绑定**，选要上线的正式域名。换到正式域名，等同于网站已上线。
- 之后用新域名访问；站点列表里也能看到当前域名。

## 配置 DNS 后无法访问

### 404（Not Found）

可能原因：域名未正确解析到 Kooboo 服务器。

排查：打开浏览器开发者工具（F12），看任意请求的 **Remote Address** 是否为 Kooboo 服务器 IP，或响应头 **Server** 是否为 Kooboo 版本号（看一项即可，Server 更易判断）。若都不是，按上一节把域名解析到 Kooboo 后再试。

### ERR_CONNECTION_RESET

可能原因：网络问题；若刚改过 DNS，也可能是 TTL 未过、解析尚未生效。

排查：换网络再访问；刚改 DNS 则等 TTL 过后再访问。

### ERR_TOO_MANY_REDIRECTS

可能原因：CNAME 配置不当，形成重定向循环。

排查：检查 CNAME 是否正确指向 Kooboo 服务器。

## 域名续费

域名快到期时，在续费页选择年限并完成续费即可。
