# 列表型数据管理

页面上的列表型数据，一般存在 **内容 → 内容** 的文件夹里。点进文件夹后，可新建、编辑、删除，也可拖拽改排序。

## 拖拽更改排序

行右侧有拖拽图标时，按住拖动即可改顺序。

<!-- TODO -->

## 开启拖拽排序

若没有拖拽图标：回到文件夹列表，点行内 **文件夹设置**。打开 **排序** 开关，**排序字段** 选 **拖拽**，再保存。之后进入文件夹即可看到拖拽图标（列表排序由排序字段控制）。
