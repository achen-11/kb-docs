# 列表型数据管理

页面上的列表型数据，一般存在 **内容 → 内容** 的文件夹里。点进文件夹后，可新建、编辑、勾选后删除，也可拖拽改排序。

## 打开内容文件夹

打开 **内容 → 内容**。点文件夹名称进入数据列表；点行内齿轮打开 **文件夹设置**。

<DocImage src="/cms/manual/list-data/folders.jpg" alt="点新闻列表进入，或点齿轮打开文件夹设置" />

## 新建、编辑、删除与拖拽

进入文件夹后，点 **新建** 添加一条。勾选行后，用上方工具条的删除图标删除（不是行内删除）。点铅笔编辑；有拖拽图标时可按住拖动改顺序。

<DocImage src="/cms/manual/list-data/entries.jpg" alt="新建、勾选后删除、铅笔编辑与拖拽排序" />

## 编辑并保存

在编辑页改字段后，点 **保存** 或 **保存并返回**。

<DocImage src="/cms/manual/list-data/edit.jpg" alt="点保存或保存并返回写入条目" />

## 开启拖拽排序

若没有拖拽图标：回到文件夹列表，点行内 **文件夹设置**。打开 **排序** 开关，**排序字段** 选 **拖拽**，再保存。之后进入文件夹即可看到拖拽图标（列表排序由排序字段控制）。

<DocImage src="/cms/manual/list-data/enable-drag.jpg" alt="在文件夹设置中打开排序并选择拖拽" />
