# 在线编辑页面

在页面真实效果上改文字和图片。点中元素后会出现菜单。文字和图片都确认后，还要点右侧工具条保存，修改才会写回页面。

## 从页面列表进入

打开 **页面**，在目标行点最右侧的铅笔图标。

<DocImage src="/cms/manual/edit-page/pages.jpg" alt="在页面列表点铅笔图标进入在线编辑" />

## 选中文字

单击要改的文字（不要双击或右键），再点菜单里的 **编辑**。

<DocImage src="/cms/manual/edit-page/select-text.jpg" alt="点选标题后选择编辑" />

## 修改并确认

直接在原处输入。点工具条上的勾选，确认这段文字。

<DocImage src="/cms/manual/edit-page/edit-text.jpg" alt="输入新标题并点勾选确认" />

## 更换图片

单击图片，再点 **图片**。勾选要用的文件，再点 **选择**。只点缩略图不会选中。

<DocImage src="/cms/manual/edit-page/choose-image.jpg" alt="勾选图片后点选择" />

## 填写替代文本

填写替代文本，点 **保存**。页面上已有样式时，这里的宽高不会改变画面。

<DocImage src="/cms/manual/edit-page/image-settings.jpg" alt="填写替代文本并保存图片设置" />

## 保存整页

上面的确认只留在编辑器里。点右侧工具条最下方的保存图标，修改才写入页面。撤销图标旁的数字是还没保存的次数。

<DocImage src="/cms/manual/edit-page/save-page.jpg" alt="点右侧工具条的保存图标写入页面" />
