# 在线编辑页面

在站点后台打开页面的真实预览，单击元素即可改文案和图片，无需先改 HTML。

## 打开在线编辑

进入 **页面** 列表，在目标行右侧点击笔形图标。

<ManualImage
  src="/cms/manual/edit-page/pages.jpg"
  alt="页面列表中点击笔形图标进入在线编辑"
  :marks="[{ x: 94.2, y: 78.5, w: 4.0, h: 7.5, label: '1' }]"
/>

## 选中文字

在预览画布中**单击**标题或其他文字（不要双击或右键）。选中后出现菜单，点击 **编辑**。

<ManualImage
  src="/cms/manual/edit-page/select-text.jpg"
  alt="单击标题后在菜单中选择编辑"
  :marks="[{ x: 30.5, y: 41.0, w: 11.5, h: 5.8, label: '1' }]"
/>

## 修改并确认

在页面原位置直接输入新文案，再点击文字工具栏左侧的勾选确认。

<ManualImage
  src="/cms/manual/edit-page/edit-text.jpg"
  alt="在原位置改标题并点击勾选确认"
  :marks="[
    { x: 12.8, y: 26.3, w: 3.8, h: 6.5, label: '1' },
    { x: 9.5, y: 36.0, w: 38.5, h: 9.0, label: '2' }
  ]"
/>

## 选择替换图片

单击图片 → 菜单中的 **图片** 打开设置，再点击预览或「点击替换」进入媒体库。勾选目标文件左上角复选框，然后点 **选择**（只点缩略图不会选中）。

<ManualImage
  src="/cms/manual/edit-page/choose-image.jpg"
  alt="媒体库中勾选图片后点击选择"
  :marks="[
    { x: 19.0, y: 27.2, w: 3.8, h: 5.5, label: '1' },
    { x: 69.8, y: 81.2, w: 11.2, h: 6.8, label: '2' }
  ]"
/>

## 填写 alt 并保存图片设置

在图片设置中可查看 src、宽高和 alt。填写说明文字后点 **保存**；若元素已有样式，宽高可能被样式覆盖。
