# 在线编辑页面

在页面真实效果上改文字和图片。点中元素后会出现菜单。文字和图片都确认后，还要点右侧工具条保存，修改才会写回页面。

## 从页面列表进入

打开 **页面**，在目标行点最右侧的铅笔图标。

<ManualImage
  src="/cms/manual/edit-page/pages.jpg"
  alt="在页面列表点铅笔图标进入在线编辑"
  :marks="[{ x: 94.2, y: 76.4, w: 3.3, h: 8.0, label: '1' }]"
/>

## 选中文字

单击要改的文字（不要双击或右键），再点菜单里的 **编辑**。

<ManualImage
  src="/cms/manual/edit-page/select-text.jpg"
  alt="点选标题后选择编辑"
  :marks="[{ x: 29.8, y: 40.6, w: 12.8, h: 6.7, label: '1' }]"
/>

## 修改并确认

直接在原处输入。点工具条上的勾选，确认这段文字。

<ManualImage
  src="/cms/manual/edit-page/edit-text.jpg"
  alt="输入新标题并点勾选确认"
  :marks="[
    { x: 13.3, y: 27.2, w: 2.7, h: 4.7, label: '1' },
    { x: 9.2, y: 34.2, w: 39.1, h: 11.7, label: '2' }
  ]"
/>

## 更换图片

单击图片，再点 **图片**。勾选要用的文件，再点 **选择**。只点缩略图不会选中。

<ManualImage
  src="/cms/manual/edit-page/choose-image.jpg"
  alt="勾选图片后点选择"
  :marks="[
    { x: 19.1, y: 26.9, w: 3.1, h: 5.6, label: '1' },
    { x: 69.6, y: 80.7, w: 11.6, h: 7.8, label: '2' }
  ]"
/>

## 填写替代文本

填写替代文本，点 **保存**。页面上已有样式时，这里的宽高不会改变画面。

<ManualImage
  src="/cms/manual/edit-page/image-settings.jpg"
  alt="填写替代文本并保存图片设置"
  :marks="[
    { x: 51.7, y: 65.6, w: 32.8, h: 8.1, label: '1' },
    { x: 67.7, y: 79.3, w: 11.7, h: 7.8, label: '2' }
  ]"
/>

## 保存整页

上面的确认只留在编辑器里。点右侧工具条最下方的保存图标，修改才写入页面。撤销图标旁的数字是还没保存的次数。
