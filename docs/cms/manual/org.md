# 组织管理

每个 Kooboo 账号都有自己的组织，账号本人是组织管理员。管理员可添加成员；成员切换到某组织后，即可管理该组织下有权限的站点。

## 添加成员

有两个入口：

- 点右上角用户名，再点下拉里的第二个选项（当前组织名称）。
- 在账号主页打开 **账号设置 → 组织 → 更多**。

进入后，输入对方的 Kooboo **用户名**，即可把该用户加入本组织。

## 切换组织

在账号主页打开 **账号设置 → 组织**，勾选要进入的组织，再点 **切换组织**。系统会退出登录；重新登录后进入所选组织，即可操作该组织下有权限的站点，或在该组织下创建站点。

## 添加成员为站点用户

成员加入组织后，通常还要在站点里分配权限，对方才能打开指定站点。

打开 **站点设置 → 用户管理**，点 **添加用户**，选择用户与角色即可。该用户会获得所选角色对应的站点权限。
