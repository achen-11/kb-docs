# 图片管理

站点图片放在左侧 **媒体库**。建议上传前先建文件夹，再把图片放到对应文件夹，方便分类管理。

## 新建文件夹分类

打开 **媒体库**。点 **新建文件夹**，按用途建好分类。文件夹名只能用字母、数字和 `.-_`（如 `product`）。

<DocImage src="/cms/manual/images/folders.jpg" alt="点新建文件夹，创建如 product 的分类文件夹" />

## 上传到对应文件夹

点文件夹名称进入后，点 **上传文件**，选择本地图片。上传完成后在列表中确认。

<DocImage src="/cms/manual/images/upload.jpg" alt="进入文件夹后点上传文件添加图片" />

## 编辑图片

鼠标放在图片上，点 **编辑** 图标进入 **编辑图片** 页。可选裁剪比例，用 **角度** 旋转，再点 **裁剪**；完成后点 **保存**。

<DocImage src="/cms/manual/images/edit.jpg" alt="在编辑图片页调整裁剪比例与角度后点裁剪" />
