# 数据类型与内容夹

> 菜单：**内容 → 数据类型**、**内容 → 内容**  
> 深链：`/_Admin/content/contentTypes?SiteId=...`、`/_Admin/content/contents?SiteId=...`

使用 [k.content](/api/content/) 读写内容前，须先在后台定义**数据类型**（字段模型），再创建**内容夹**（API 中的文件夹名）。

## 1. 创建数据类型

1. 进入 **内容 → 数据类型**。
2. 点击 **新建数据类型**。
3. 填写类型名称（如 `Article`、`Product`），建议英文标识。
4. 点击 **+ 添加字段**，为每条字段配置：
   - **名称**：API 与模板中使用的字段键（英文）
   - **显示名**：后台表单标签
   - **控件类型**：文本、日期、图片、下拉等
   - **多语言**：是否按语言分别存值
   - **摘要字段**：是否在列表中作为摘要展示
   - **用户可编辑**：是否允许在前端由用户修改

<!-- 待图：/cms/content/data-types/01-list.png -->

::: tip
先完成数据类型再建内容夹。修改已发布字段的类型或删除字段可能影响已有内容，请谨慎操作。
:::

## 2. 创建内容夹

1. 进入 **内容 → 内容**。
2. 点击 **新建**，选择 **文件夹**（多条内容）或 **单条内容**（仅一条记录）。
3. 配置：
   - **名称**：文件夹标识，即 API 访问键（如 `Article` → `k.content.Article`）
   - **显示名**：后台显示名称
   - **数据类型**：选择上一步创建的类型
   - **预览 URL**（可选）：详情页或预览模板
   - **分页大小**：列表默认每页条数
   - **可排序**：是否支持手动排序
   - **隐藏**：是否在后台列表中隐藏

<!-- 待图：/cms/content/data-types/02-folder.png -->

::: tip 命名规范
内容夹的 **名称** 即脚本中的属性名：`k.content.Article.all()` 中的 `Article` 须与此处一致。
:::

## 3. 录入内容

在 **内容 → 内容** 中打开对应文件夹，新建或编辑条目。保存后可通过 `k.content.{文件夹}.get()`、`findAll()` 等在 KScript 中访问。
