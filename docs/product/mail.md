# 邮箱

> Kooboo 邮箱用于收发邮件、管理联系人、配置 IMAP / SMTP 与邮件扩展模块。

## 如何打开

| 项目 | 说明 |
|------|------|
| 顶部入口 | 点击顶部导航的 **邮箱** 按钮 |
| 邮箱深链 | `/_Admin/kmail/inbox` |
| 设置深链 | `/_Admin/kmail-settings/addresses` |
| 前端路由 | `/kmail`、`/kmail-settings` |

邮箱是账户级功能。若某些邮箱能力不可用，先确认域名是否已经接入 Kooboo DNS；界面文案提示邮箱功能面向使用 Kooboo DNS 的域名开放。

## 邮箱主界面

| 菜单 | 用途 |
|------|------|
| 收件箱 | 查看收到的邮件，按地址或文件夹筛选 |
| 撰写 | 新建邮件草稿并发送 |
| 已发送 | 查看发出的邮件 |
| 草稿 | 继续编辑未发送邮件 |
| 垃圾邮件 | 查看 Spam |
| 已删除 | 查看 Trash |
| 文件夹 | 管理自定义邮件文件夹 |
| 搜索 | 搜索邮件，支持高级搜索入口 |
| 日历 | 创建或查看邮件相关日程 |

## 邮箱设置

| 设置页 | 用途 |
|--------|------|
| 邮箱地址 | 添加发件邮箱、设置默认地址、维护签名 |
| 联系人 | 维护常用联系人 |
| 安全报告 | 查看邮件安全相关报告 |
| IMAP | 查看或生成 IMAP 连接信息 |
| 邮件扩展模块 | 管理邮件模块，进入模块编辑器 |
| Inbox Logo | 配置收件箱标识 |
| SMTP | 在支持的环境中配置 SMTP |

## 典型工作流

| 场景 | 顺序 |
|------|------|
| 开通发信 | 控制台域名/DNS -> 邮箱设置 -> 邮箱地址 -> 设为默认地址 |
| 发送业务通知 | 邮箱地址 -> [k.mail](/api/mail/) -> 业务 API 或定时任务 |
| 迁移邮件 | 邮箱设置 -> 迁移入口（若环境开放） -> 检查收件箱与已发送 |
| 自定义邮件能力 | 邮件扩展模块 -> 模块编辑器 -> 测试收发 |

## 与 KScript 的关系

| 后台邮箱 | KScript API |
|----------|-------------|
| 配置发件地址、默认邮箱、IMAP / SMTP | 使用 [k.mail](/api/mail/) 发信、读取邮件或接入业务流程 |
| 管理联系人与邮箱内容 | 在业务 API 中按需调用邮件能力 |
| 邮件扩展模块 | 与 [k.module](/api/module/) 和站点资源组合 |
