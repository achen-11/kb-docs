# 控制台

> 账户与组织级管理入口，用于域名、组织、数据中心、会员、AI 配置、订单、余额与续费。

## 如何打开

| 项目 | 说明 |
|------|------|
| 顶部入口 | 点击顶部导航右侧的 **控制台** 图标 |
| 深链 | `/_Admin/kconsole` |
| 前端路由 | `/kconsole` |

控制台是账户级页面，不是某个站点内部菜单。它适合先处理账户、组织、域名与费用，再回到某个站点后台继续配置 CMS。

## 左侧菜单

| 菜单 | 用途 | 典型操作 |
|------|------|----------|
| 域名 | 管理账户下域名 | 添加域名、DNS、绑定、搜索、续费 |
| 组织 | 管理组织与成员 | 切换组织、添加成员、部门 |
| 数据中心 | 查看或选择服务数据中心 | 站点服务位置、数据中心信息 |
| Google SC | Search Console 相关配置 | 添加站点、Sitemap、分析 |
| 会员 | 组织会员计划 | 查看会员、续费 |
| AI 配置 | 组织级 AI 配置 | 配置 AI 相关账户设置 |
| 订单 | 订单记录与支付检查 | 查看订单、确认订单 |
| 余额 | 账户余额与充值 | 充值、余额支付 |
| 续费 | 管理即将到期项目 | 域名、会员等续费入口 |

## 常见工作流

| 场景 | 建议顺序 |
|------|----------|
| 新组织上线 | 组织 -> 余额 -> 域名 -> 会员 |
| 域名准备 | 域名 -> DNS -> 域名绑定 -> 回到 [CMS 域名管理](/cms/settings/domains.md) |
| AI 能力准备 | AI 配置 -> 余额 -> 站点 [AI 服务](/cms/settings/ai-service.md) |
| 费用核对 | 订单 -> 余额 -> 续费 |

## 与站点后台的分工

| 控制台做 | 站点后台做 |
|----------|------------|
| 管理账户级域名、订单、余额、组织 | 配置某个站点的 Base URL、域名绑定和服务集成 |
| 配置组织级 AI 或会员 | 配置站点级 AI 服务、MCP、AI 函数 |
| 查看账户服务与续费 | 调整具体站点的页面、内容、Hook、Cookie |
