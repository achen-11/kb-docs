# 开发者模式

> 在站点后台中打开类 VS Code 的开发体验，同时编辑多个站点资源并调试代码。

## 如何打开

| 项目 | 说明 |
|------|------|
| 顶部入口 | 进入站点后台后，点击顶部 **开发者模式** 图标 |
| 深链 | `/_Admin/dev-mode?SiteId={站点GUID}` |
| 前端路由 | `/dev-mode` |

开发者模式是站点级能力，需要带 `SiteId`。顶部弹窗中的说明包括：类似 VS Code 开发体验、同时打开编辑多个文件、调试代码。

## 主要区域

| 区域 | 用途 |
|------|------|
| 左侧资源面板 | 页面、布局、视图、脚本、样式、代码、菜单、模块、表单等资源入口 |
| 标签页 | 同时打开多个文件或资源 |
| 编辑区 | 编辑 HTML、CSS、JavaScript、CodeBlock 或二进制/图片资源 |
| 调试面板 | 查看调试相关信息 |
| 搜索面板 | 在站点资源中查找内容 |

## 适合处理什么

| 任务 | 推荐原因 |
|------|----------|
| 同时改 Page、Layout、View | 多标签可以保持上下文 |
| 调整 JS / CSS 资源 | 适合快速跳转和对照 |
| 维护 CodeBlock | 与页面和 API 资源一起打开 |
| 排查模板问题 | 可以从页面、视图、样式和脚本之间快速切换 |

## 与 CMS 开发菜单的关系

| CMS 开发菜单 | 开发者模式 |
|--------------|------------|
| 更适合单个资源的结构化表单、列表、权限按钮 | 更适合多文件编辑、连续调试和上下文切换 |
| 每类资源单独进入页面 | 在同一工作区打开多类资源 |
| 文档按菜单逐页说明 | 文档按资源类型参考模板和 API |

## 退出前检查

离开开发者模式时，如果仍有打开的标签或未保存状态，界面会提示确认。建议先保存资源，再回到站点后台页面预览。
