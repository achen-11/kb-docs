# AI Claw / AI Chat

> 用自然语言描述目标，在站点级 AI 工作台中查看会话、自动化任务、任务进度和人工协助。

## 如何打开

| 项目 | 说明 |
|------|------|
| 顶部入口 | 进入站点后台后，点击顶部 **AI** 按钮 |
| 深链 | `/_Admin/ai-chat/overview?SiteId={站点GUID}` |
| 指定面板 | `/_Admin/ai-chat/overview?SiteId={站点GUID}&tab={面板}` |
| 前端路由 | `/ai-chat/overview` |
| 页面层级 | 站点级页面，必须带 `SiteId` |

AI Claw 是站点级 AI 工作台。它与右下角 [AI 悬浮助手](./ai-floating-assistant.md) 使用同一套对话能力，但更适合集中查看会话、任务、固定例行事项和人工协助。

<DocImage src="/product/ai-chat/ai-chat-overview.png" alt="AI Claw 总览：任务进度、AI 实时发现、固定例行事项、全部任务列表和对话区" width="1120" />

## 页面结构

AI Claw 的界面通常分为三块：

| 区域 | 怎么用 |
|------|--------|
| 顶部栏 | 切换站点、返回 AI 创作入口、查看当前站点与顶部 AI 入口 |
| 左侧面板 | 查看任务总览；也可以进入会话历史、固定例行事项、全部任务、人工帮助等面板 |
| 右侧对话区 | 与 Kooboo 自助智能体对话，选择模型、上传图片、查看工具调用与确认项 |

部分环境会先显示 **任务总览**，其中包含 **AI 实时发现**、**固定例行事项**、**全部任务列表** 三个卡片；点击卡片右侧 **更多** 可进入对应完整面板。较新的界面也可能直接用左侧图标切换会话历史、固定事项、任务列表和人工帮助。

## 对话区

右侧对话区与悬浮助手的核心操作一致。

| 控件 | 说明 |
|------|------|
| 输入框 | 输入自然语言目标，例如“检查这个站点的首页内容是否完整” |
| 模型下拉框 | 选择当前会话使用的 AI Provider 和模型；可选项来自控制台与站点 AI 配置 |
| 自动执行 | 开启后，部分需要确认的操作会自动执行；白名单外的敏感操作仍会按前端规则处理 |
| 图片上传 | 给 AI 添加截图或图片上下文 |
| 发送 | 点击右下角发送按钮，或使用 `Ctrl + Enter` |
| 停止 | 回答生成中时，发送按钮会变成停止按钮 |

如果 AI 准备执行写入、修改代码或调用工具，界面会展示确认项。站点能调用哪些 MCP、AI 函数和内置工具，由 [CMS：AI 服务](/cms/settings/ai-service.md) 决定。

## 固定例行事项

固定例行事项用于把一段 AI 指令设置成一次性或循环执行的自动化任务。

<DocImage src="/product/ai-chat/fixed-tasks.png" alt="AI Claw 固定例行事项：空状态和新增按钮" width="1120" />

点击固定例行事项面板右上角 **+**，打开新建弹窗。

<DocImage src="/product/ai-chat/fixed-task-dialog.png" alt="AI Claw 新建固定例行事项弹窗：名称、状态、执行类型、间隔、单位和执行逻辑" width="1120" />

| 字段 | 填什么 |
|------|--------|
| 事项名称 | 便于识别的任务名，建议写清楚对象和目标，例如“每周检查首页链接” |
| 状态 | 选择暂停或运行中；未准备好前先暂停 |
| 执行类型 | 选择单次执行或循环执行 |
| 执行间隔 | 循环执行时填写间隔数量 |
| 单位 | 选择天、小时、分钟等时间单位 |
| 执行逻辑 | 写清楚 AI 要检查、生成、提醒或调用的目标；避免只写一句模糊命令 |

保存后任务会出现在固定例行事项列表。列表中可编辑、删除或立即执行任务；如果任务正在运行，界面会避免重复触发。

## 全部任务列表

全部任务列表展示 AI 自动化任务的运行记录。

<DocImage src="/product/ai-chat/task-list.png" alt="AI Claw 全部任务列表：全部、等待中、运行中、已完成、失败筛选" width="1120" />

| 筛选 | 说明 |
|------|------|
| 全部 | 查看所有任务记录 |
| 等待中 | 查看尚未开始执行的任务 |
| 运行中 | 查看正在执行的任务 |
| 已完成 | 查看已完成任务 |
| 失败 | 排查执行失败的任务 |

点击某条任务记录后，右侧会显示任务对话或运行日志。对于可继续的任务，界面会提供 **继续会话** 按钮，把任务日志带入一段新的对话继续处理。

## 会话历史与人工帮助

| 面板 | 说明 |
|------|------|
| 会话历史 | 查看当前总览会话或全部会话，可重命名、删除、导入或导出会话 |
| 人工帮助 | 在支持的环境中查看认证专家、提交协助任务、跟进任务消息和验收状态 |

人工帮助可能涉及专家服务、支付和验收流程；这里把它作为 AI 工作台的一部分说明。账户余额、订单和支付核对仍回到 [控制台：余额](./console/balance.md) 与 [控制台：订单](./console/orders.md)。

## 使用前先确认

| 检查项 | 位置 |
|--------|------|
| 组织级 AI Provider 是否已配置 | [控制台：AI 配置](./console/ai-config.md) |
| 账户余额是否足够 | [控制台：余额](./console/balance.md) |
| 站点是否启用 MCP 或 AI 函数 | [CMS：AI 服务](/cms/settings/ai-service.md) |
| 是否需要让 AI 引用当前代码 | [开发者模式](./developer-mode.md) 中右键资源标签，选择 **添加代码引用** |

## 与 AI 悬浮助手的区别

| AI Claw / AI Chat | AI 悬浮助手 |
|-------------------|-------------|
| 独立页面，适合集中处理会话、固定事项、任务列表和人工协助 | 浮在当前后台页面右下角，适合边操作边问 |
| 适合查看任务进度、回到历史会话、继续任务日志 | 适合基于当前页面上下文获得建议或快速发起修改 |
| 进入后主要围绕 AI 工作台操作 | 保留当前 CMS 页面，不打断正在做的配置 |

## 典型工作流

| 目标 | 操作 |
|------|------|
| 开始一段站点 AI 对话 | 站点后台 -> 顶部 **AI** -> 输入目标 -> 选择模型 -> 发送 |
| 设置定期巡检 | AI Claw -> 固定例行事项 -> **+** -> 填名称、周期、执行逻辑 -> 保存 |
| 排查任务运行结果 | AI Claw -> 全部任务列表 -> 选择状态筛选 -> 点击任务记录查看日志 |
| 让 AI 理解当前代码 | 开发者模式打开资源 -> 右键标签添加代码引用 -> 回到 AI 对话继续提问 |
| 需要人工协助 | AI Claw -> 人工帮助 -> 选择专家 -> 填任务标题和描述 |
