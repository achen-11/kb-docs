# AI Claw / AI Chat

> 用自然语言描述目标，协助管理站点，并在一处查看智能体进度与本周任务。

## 如何打开

| 项目 | 说明 |
|------|------|
| 顶部入口 | 进入站点后台后，点击顶部 **AI** 按钮 |
| 深链 | `/_Admin/ai-chat/overview?SiteId={站点GUID}` |
| 前端路由 | `/ai-chat/overview` |

AI Claw 是站点级入口。顶部弹窗说明它与全局悬浮 AI 助手使用一致的能力与体验。

## 主要区域

| 区域 | 用途 |
|------|------|
| 对话面板 | 输入自然语言目标，查看 AI 回复、工具调用与确认项 |
| 会话历史 | 查看站点内不同会话，继续之前的任务 |
| 任务列表 | 查看智能体任务、进度、运行状态 |
| 固定例行事项 | 创建一次性或循环执行的自动化事项 |
| 设置面板 | 选择模型、查看上下文、调整会话相关设置 |
| 人工协助 | 在支持的环境中请求专家协助、处理验收或支付消息 |

## 适合哪些任务

| 场景 | 说明 |
|------|------|
| 站点管理 | 让 AI 辅助理解当前站点结构、页面、内容与任务 |
| 开发辅助 | 结合站点资源上下文生成修改建议，并在确认后应用 |
| 任务跟踪 | 查看自动化任务、固定例行事项、运行历史 |
| 内容巡检 | 结合站点 AI 服务与内容能力做检查或建议 |

## 使用前先确认

| 检查项 | 位置 |
|--------|------|
| 站点是否启用 AI 能力 | [CMS：AI 服务](/cms/settings/ai-service.md) |
| 是否需要自定义 AI 函数 | [AI 服务：AI 函数](/cms/settings/ai-service.md#ai-函数) |
| 是否需要 MCP Client 调用站点能力 | [AI 服务：MCP 服务](/cms/settings/ai-service.md#mcp-服务) |
| 账户余额或 AI 配置 | [控制台](./console.md) 与 [充值与账单](./billing.md) |

## 与 AI 悬浮助手的区别

| AI Claw / AI Chat | AI 悬浮助手 |
|-------------------|-------------|
| 独立页面，适合集中查看会话、任务与固定事项 | 浮在当前后台页面右下角，适合边操作边问 |
| 适合处理较长任务和历史追踪 | 适合基于当前页面上下文获得建议 |
