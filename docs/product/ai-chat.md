# AI Claw / AI Chat

> 用自然语言描述目标，在站点级 AI 工作台中对话、预览站点、管理自动化任务，并在需要时转交人工协助。

## 如何打开

| 项目 | 说明 |
|------|------|
| 顶部入口 | 进入站点后台后，点击顶部 **AI** 按钮 |
| 深链 | `/_Admin/ai-chat/overview?SiteId={站点GUID}` |
| 指定左侧面板 | `/_Admin/ai-chat/overview?SiteId={站点GUID}&tab={面板}` |
| 数据子菜单 | 再加 `&submenu={子项}`，例如 `submenu=content-model` |
| 前端路由 | `/ai-chat/overview` |
| 页面层级 | 站点级页面，必须带 `SiteId` |

常用 `tab` 取值：`chat`（默认，可不写）、`fix`、`task`、`data`、`design`、`service`、`setting`。

AI Claw 与右下角 [AI 悬浮助手](./ai-floating-assistant.md) 共用对话与工具能力。区别在于：Claw 是独立工作台，对话区左侧可切换会话 / 任务 / 数据 / 设计等面板，右侧是可切换的站点工作区（预览、代码、媒体、蓝图）。

<DocImage src="/product/ai-chat/ai-chat-overview.png" alt="AI Claw：左侧对话、右侧实时站点预览工作区" width="1120" />

## 页面结构

界面通常分为四块：

| 区域 | 怎么用 |
|------|--------|
| 顶部栏 | 切换站点、返回 **AI 创作**、打开顶部 **AI** 入口 |
| 最左侧图标栏 | 切换会话历史、固定例行事项、全部任务、数据、设计、人工帮助、设置；可用 `Cmd/Ctrl + B` 展开或收起旁边的列表面板 |
| 中间对话区 | 与 **Kooboo 自助智能体** 对话；标题栏可打开 **人工帮助** |
| 右侧工作区 | 实时预览站点，或切换到代码、媒体库、应用蓝图 |

默认进入会话模式时，列表面板可能收起，只保留图标栏与对话区。点击图标栏中的会话、固定事项、任务等入口，或按 `Cmd/Ctrl + B`，可展开左侧列表面板。

## 对话区

中间对话区是主要操作面。

| 控件 | 说明 |
|------|------|
| 输入框 | 输入自然语言目标，例如“检查这个站点的首页内容是否完整” |
| 模型选择 | 选择 Provider 与模型；部分模型还可设置推理强度（如低 / 中 / 高 / 超高） |
| 执行策略 | 快捷切换 **每次确认**、**仅自动执行允许项**、**自动执行**；可从下拉菜单进入完整设置 |
| 图片上传 | 给 AI 添加截图或图片上下文 |
| 发送 | 点击发送按钮，或按设置中的发送快捷键（默认 `Enter`，也可改为 `Cmd/Ctrl + Enter`） |
| 停止 | 回答生成中时，发送按钮会变成停止 |

如果 AI 准备执行写入、修改代码或调用工具，界面会展示确认项。站点能调用哪些 MCP、AI 函数和内置工具，由 [CMS：AI 服务](/cms/settings/ai-service.md) 决定。

对话进行中还可能出现：

| 能力 | 说明 |
|------|------|
| 当前待办 | AI 把多步目标拆成待办列表，并在对话旁跟踪完成情况 |
| 下一步推荐 | 一轮结束后给出可继续的方向，可直接发送或填入输入框 |
| 建站进度 | 建站类任务会显示里程碑进度 |

## 右侧工作区

右侧工作区与对话并排，方便边聊边看结果。顶部可用工作区模式切换：

| 模式 | 说明 |
|------|------|
| 浏览器 | **实时站点预览**：地址栏跳转页面、切换桌面 / 平板 / 手机视口、选择页面元素并添加注释后发给 AI |
| 代码 | 浏览站点资源树并预览源码，可引用代码或跳到 [开发者模式](./developer-mode.md) |
| 媒体库 | 在有权限时查看站点媒体资源 |
| 应用蓝图 | 站点存在应用蓝图时，查看结构并就蓝图内容继续与 AI 讨论 |

<DocImage src="/product/ai-chat/workspace-code.png" alt="AI Claw 右侧工作区：站点代码树与源码预览" width="1120" />

浏览器预览底部还可打开：

| 工具 | 说明 |
|------|------|
| 运行日志 | 查看预览页捕获的错误、警告与普通日志，并可让 AI 排查 |
| 网络请求 | 查看失败、超时或异常请求，并可让 AI 排查 |
| Iframe 预览说明 | 了解内嵌预览的限制；完整设备能力、登录态、支付跳转等仍以新标签页打开站点为准 |

AI 正在生成页面时，预览区可能显示构建进度；首个页面就绪后会自动展示预览。工作区可拖动分隔条调整宽度，或从对话区标题栏收起 / 展开。

## 左侧面板

### 会话历史

点击会话历史图标并展开面板后，可管理当前站点的对话。

| 操作 | 说明 |
|------|------|
| 总览会话 / 全部对话 | 切换只看总览会话，或查看全部会话 |
| 开启新对话 | 新建空白会话 |
| 导入 | 导入会话文件 |
| 重命名 / 删除 | 管理历史会话 |

### 固定例行事项

把一段 AI 指令设成一次性或循环执行的自动化任务。

<DocImage src="/product/ai-chat/fixed-tasks.png" alt="AI Claw 固定例行事项：空状态与新增按钮" width="1120" />

点击面板右上角 **+**，打开新建弹窗。标题为 **新建自动化任务**；也可点 **使用模板** 从电商、内容巡检、开发质量、站点维护等模板开始。

<DocImage src="/product/ai-chat/fixed-task-dialog.png" alt="新建自动化任务：任务名称、提示词、执行方式、间隔、开始时间、模型和状态" width="720" />

| 字段 | 填什么 |
|------|--------|
| 任务名称 | 便于识别的名称，建议写清对象和目标 |
| 提示词 | AI 要检查、生成、提醒或调用的完整说明 |
| 执行方式 | 单次或循环 |
| 重复间隔 | 循环时填写数量与单位（天、小时、分钟等） |
| 开始时间 | 首次或下次计划执行时间 |
| 模型 | 该自动化任务使用的 AI 模型 |
| 状态 | 未启用或已启用；未准备好前先保持未启用 |

保存后可在列表中编辑、删除或立即运行；任务正在运行时界面会避免重复触发。

### 全部任务列表

展示 AI 自动化任务的运行记录。

<DocImage src="/product/ai-chat/task-list.png" alt="AI Claw 全部任务列表：按任务状态筛选，右侧查看执行记录" width="1120" />

| 筛选 | 说明 |
|------|------|
| 全部 | 查看所有任务记录 |
| 等待中 | 尚未开始执行 |
| 运行中 | 正在执行 |
| 已完成 | 已完成任务 |
| 失败 | 执行失败，便于排查 |

从左侧选中一条任务后，中间会显示完整执行记录。对可继续的任务，界面会提供 **继续会话**，把任务日志带入新对话继续处理。

### 数据

在 AI 工作台内直接查看或维护内容与电商数据，无需离开对话上下文。

<DocImage src="/product/ai-chat/data-content.png" alt="AI Claw 数据面板：内容模型、内容数据、产品类型、分类与产品" width="1120" />

| 分组 | 子项 |
|------|------|
| 内容 | 内容模型、内容数据 |
| 电商 | 产品类型、分类、产品 |

深链示例：`/_Admin/ai-chat/overview?SiteId={站点GUID}&tab=data&submenu=content-model`。

### 设计

查看和调整站点设计变量（颜色、字体、圆角、间距、阴影等）。若尚未初始化，可先 **初始化设计变量**，再保存修改。

<DocImage src="/product/ai-chat/design.png" alt="AI Claw 设计参数面板：初始化设计变量" width="1120" />

### 人工帮助

在支持的环境中选择专家、提交协助工单，并跟进消息与验收状态。也可从对话区标题栏的 **人工帮助** 直接发起。

人工帮助可能涉及专家服务、支付和验收；账户余额、订单和支付核对仍回到 [控制台：余额](./console/balance.md) 与 [控制台：订单](./console/orders.md)。

### 设置

打开 **AI Chat 设置**，管理个人偏好与站点级执行策略。

<DocImage src="/product/ai-chat/settings.png" alt="AI Chat 设置：个人偏好与站点执行策略" width="1120" />

| 分区 | 作用范围 | 内容 |
|------|----------|------|
| 个人偏好 | 当前浏览器 | 发送快捷键、AI 工作期间再次发送（加入队列 / 中断并发送）、新站点默认执行策略、完成通知 |
| 站点执行策略 | 全站共享 | **每次确认**、**仅自动执行允许项**、**自动执行**；允许项模式下可管理可自动执行的 function |

修改站点执行策略需要相应 AI 编辑权限。对话区输入框旁的执行策略按钮可快速切换，也可跳转到本页做完整配置。

## 使用前先确认

| 检查项 | 位置 |
|--------|------|
| 组织级 AI Provider 是否已配置 | [控制台：AI 配置](./console/ai-config.md) |
| 账户余额是否足够 | [控制台：余额](./console/balance.md) |
| 站点是否启用 MCP 或 AI 函数 | [CMS：AI 服务](/cms/settings/ai-service.md) |
| 执行策略是否符合环境风险 | AI Claw -> 设置，或输入框旁的执行策略按钮 |
| 是否需要让 AI 引用当前代码 | 右侧 **代码** 工作区引用，或 [开发者模式](./developer-mode.md) 中右键资源标签 **添加到对话** |

## 与 AI 悬浮助手的区别

| AI Claw / AI Chat | AI 悬浮助手 |
|-------------------|-------------|
| 独立工作台：对话 + 左侧面板 + 右侧站点工作区 | 浮在当前后台页面右下角，适合边操作边问 |
| 适合建站、预览、看代码、跑固定任务、查任务日志 | 适合基于当前 CMS 页面上下文快速提问 |
| 进入后主要围绕 AI 工作台操作 | 保留当前 CMS 页面，不打断正在做的配置 |

## 典型工作流

| 目标 | 操作 |
|------|------|
| 开始一段站点 AI 对话 | 站点后台 -> 顶部 **AI** -> 输入目标 -> 选择模型与执行策略 -> 发送 |
| 边对话边看前台效果 | 保持右侧 **浏览器** 工作区展开 -> 让 AI 修改后刷新预览 |
| 给预览页提修改意见 | 预览工具栏选择元素 -> 添加注释 -> 填入输入框或直接发送 |
| 排查预览报错 | 打开 **运行日志** 或 **网络请求** -> **让 AI 排查** |
| 设置定期巡检 | 固定例行事项 -> **+** -> 填名称、提示词、周期与模型 -> 创建 |
| 排查任务运行结果 | 全部任务列表 -> 选择状态筛选 -> 点击记录查看日志 |
| 在工作台内改内容或商品 | 数据面板 -> 选择内容 / 电商子项 |
| 调整设计变量 | 设计面板 -> 初始化或编辑变量 -> 保存 |
| 需要人工协助 | 标题栏 **人工帮助**，或左侧人工帮助面板 |
