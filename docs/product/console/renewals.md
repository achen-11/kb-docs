# 控制台：续费

> 汇总当前组织需要续费的域名和会员项目，按类型筛选并进入对应续费流程。

## 如何打开

| 项目 | 说明 |
|------|------|
| 菜单路径 | 顶部 **控制台** -> 左侧 **续费** |
| 深链 | `/_Admin/kconsole/renew` |
| 前端路由 | `/kconsole/renew` |
| 可见身份 | 组织管理员 |

续费页不直接完成支付，它负责找到需要处理的续费项，并把你带到域名续费弹窗或会员页。

<DocImage src="/product/console/renewals-overview.png" alt="控制台续费列表（金额与域名已脱敏）" width="1120" />

## 筛选标签

表格左上方提供筛选标签：

| 标签 | 说明 |
|------|------|
| All | 显示全部续费项 |
| Domain Renew | 只显示域名 |
| Membership Renew | 只显示会员 |

前端代码中保留了 Application 类型的处理，但当前常规标签只展示域名和会员。

## 续费列表

表格显示：

| 列 | 说明 |
|----|------|
| Item | 项目类型标签和名称 |
| Status | 正常或已过期 |
| Expire Date | 到期日期 |
| Charge Period | 计费周期，年或月 |
| Renew Price | 续费价格和币种 |
| Renew Now | 进入对应续费流程 |

状态由 `expiredIn` 判断：到期时间早于当前时间时显示已过期，否则显示正常。

## 域名续费

域名续费项点击 `Renew Now` 后会打开域名续费弹窗。

| 字段 | 说明 |
|------|------|
| Domain | 当前域名，只读 |
| Period | 续费年限，1 到 10 年 |
| OK | 创建域名续费订单 |

确认后会跳转到 [订单结账页](./orders.md#结账页)。

## 会员续费

会员续费项点击 `Renew Now` 后会跳转到：

```text
/_Admin/kconsole/member
```

在 [会员](./membership.md) 页确认当前计划和套餐后，再创建会员续费订单。

## 常见工作流

| 场景 | 顺序 |
|------|------|
| 统一查看到期项 | 续费 -> All |
| 只处理域名 | 续费 -> Domain Renew -> Renew Now -> 结账 |
| 只处理会员 | 续费 -> Membership Renew -> 会员页 -> 结账 |
| 付款后复核 | 订单 -> 续费 -> 确认项目状态 |

## 与订单页的关系

| 续费页 | 订单页 |
|--------|--------|
| 找到要续费的项目，并创建续费订单 | 查看订单是否支付、是否交付 |
| 面向“到期项” | 面向“已创建订单” |
