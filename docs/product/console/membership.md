# 控制台：会员

> 查看当前组织会员计划，购买或续费会员，并进入结账流程。

## 如何打开

| 项目 | 说明 |
|------|------|
| 菜单路径 | 顶部 **控制台** -> 左侧 **会员** |
| 深链 | `/_Admin/kconsole/member` |
| 前端路由 | `/kconsole/member` |
| 可见身份 | 组织管理员 |

会员页管理的是当前组织的会员计划。切换组织后，看到的当前计划、套餐状态和订单也会随组织变化。

<DocImage src="/product/console/membership-overview.png" alt="控制台会员套餐与当前计划" width="1120" />

## 当前计划

如果当前组织已有会员计划，页面顶部会显示：

| 项目 | 说明 |
|------|------|
| Current Plan | 当前会员计划名称 |
| Expired At | 到期时间 |
| Renew | 按当前会员等级创建续费订单 |

如果当前组织是 Partner，或服务等级高于普通会员等级，页面会显示 Partner 相关提示，不再展示普通购买流程。

## 套餐卡片

页面下方是会员套餐卡片。

| 区域 | 说明 |
|------|------|
| 标题与 Headline | 套餐名称和简要说明 |
| 价格 | 显示币种、价格、按月或按年 |
| Purchase Now | 创建会员购买订单 |
| In Use | 当前正在使用的套餐，按钮禁用 |
| 功能列表 | 显示该套餐包含的在线功能 |

点击 `Purchase Now` 或顶部 `Renew` 后，前端会创建会员订单，并跳转到：

```text
/_Admin/kconsole/checkOrder?orderId={orderId}
```

后续支付流程见 [订单：结账页](./orders.md#结账页)。

## 常见工作流

| 场景 | 顺序 |
|------|------|
| 查看当前会员状态 | 会员 -> 查看 Current Plan 和 Expired At |
| 首次购买会员 | 会员 -> 选择套餐 -> Purchase Now -> 结账 |
| 续费当前会员 | 会员 -> Renew -> 结账 |
| 核对会员订单 | 会员 -> 结账 -> [订单](./orders.md) |

## 与续费页的关系

| 会员页 | 续费页 |
|--------|--------|
| 查看套餐详情、购买或续费会员 | 汇总域名和会员等到期项 |
| 点击购买或续费会创建订单 | 点击会员续费会跳回会员页 |
