# 控制台：订单

> 查看当前组织订单，继续支付未完成订单，并在结账页选择支付方式。

## 如何打开

| 项目 | 说明 |
|------|------|
| 菜单路径 | 顶部 **控制台** -> 左侧 **订单** |
| 订单列表深链 | `/_Admin/kconsole/consoleOrder` |
| 结账页深链 | `/_Admin/kconsole/checkOrder?orderId={orderId}` |
| 前端路由 | `/kconsole/consoleOrder`、`/kconsole/checkOrder` |
| 可见身份 | 组织管理员 |

订单页显示当前组织的订单记录。域名购买、域名续费、会员购买、充值等流程都会创建订单。

## 订单列表

页面顶部会显示订单提示和不可退款提醒。下面的表格显示：

| 列 | 说明 |
|----|------|
| Line Title | 订单标题 |
| Total Amount | 订单总金额与币种 |
| Date | 创建时间 |
| Type | 订单类型 |
| Is Paid | 是否已支付 |
| Is Delivered | 是否已交付 |
| Pay | 未支付且可支付的订单显示该按钮 |

订单类型标签包括购买、会员、带宽、服务、服务器、充值、API 市场、应用市场、续费等。

点击 `Pay` 会进入结账页：

```text
/_Admin/kconsole/checkOrder?orderId={orderId}
```

## 结账页

结账页左侧是订单摘要与支付方式，右侧是订单金额汇总。

左侧主要区域：

| 区域 | 说明 |
|------|------|
| 订单标题与 Summary | 显示订单说明 |
| Payment Method | `Credit Card`、`Wechat Pay` 两个 Tab |
| 已保存信用卡 | 显示卡尾号，可直接选择 |
| 新增信用卡 | 点击加号后填写卡信息 |
| 微信支付二维码 | 切换到 `Wechat Pay` 后生成二维码并轮询支付状态 |

右侧金额汇总：

| 区域 | 说明 |
|------|------|
| Order Summary | 订单明细项 |
| Subtotal | 小计 |
| VAT | 税费 |
| Total | 总额与币种 |
| Submit Payment / Scan To Pay | 提交信用卡支付，或提示扫码支付 |

## 信用卡支付

如果选择已有信用卡，直接点击 `Submit Payment`。

如果新增信用卡，需要填写：

| 字段 | 说明 |
|------|------|
| Card Number | 卡号 |
| Expiration Date | 月份与年份 |
| Name on Card | 持卡人姓名 |
| CVC | 安全码 |

提交后如果后端返回跳转地址，页面会跳转到该地址继续支付；如果支付成功且无需跳转，会回到订单列表。

## 微信支付

切换到 `Wechat Pay` 后，页面会生成二维码并每秒检查支付状态。支付完成后会自动回到订单列表。

如果二维码一直没有变化或支付后没有跳转，先检查订单是否仍在订单列表中显示未支付，再重新进入结账页。

## 常见工作流

| 场景 | 顺序 |
|------|------|
| 继续支付未完成订单 | 订单 -> Pay -> 结账页 |
| 域名购买后付款 | [域名购买](./domains.md#购买域名) -> 结账页 -> 订单列表核对 |
| 充值后付款 | [余额](./balance.md#充值) -> 结账页 -> 余额页核对 |
| 会员购买后付款 | [会员](./membership.md) -> 结账页 -> 会员页核对 |

## 与余额、续费的关系

| 页面 | 负责什么 |
|------|----------|
| [余额](./balance.md) | 发起充值、查看收支记录 |
| 订单 | 查看订单和支付状态 |
| [续费](./renewals.md) | 找到即将到期或已到期项目，并创建续费订单 |
