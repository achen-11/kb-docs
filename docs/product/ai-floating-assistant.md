# AI 悬浮助手

> 站点后台右下角的全局 AI 面板，基于当前页面上下文提供建议、对话和操作确认。

## 出现位置

AI 悬浮助手挂载在站点后台布局中。进入站点后台后，在右下角可以看到 AI 浮动按钮；部分账户级页面或受限站点环境可能不会显示。

| 项目 | 说明 |
|------|------|
| 入口 | 右下角 AI 浮动按钮 |
| 层级 | 站点级上下文 |
| 上下文来源 | 当前路由、页面标题、`SiteId`、会话历史 |

## 面板模式

| 模式 | 用途 |
|------|------|
| 悬浮面板 | 默认模式，适合快速提问或执行推荐操作 |
| 侧栏 | 把聊天固定到右侧，边看后台页面边操作 |
| 全屏 | 处理较长对话、审阅修改或查看历史 |

## 常见控件

| 控件 | 说明 |
|------|------|
| 新建会话 | 从当前页面上下文开始一段新对话 |
| 会话历史 | 回到之前的站点会话 |
| 推荐操作 | 未展开时可能显示“我可以...”的快捷建议 |
| 工具调用确认 | AI 需要执行操作或写入修改时，先展示确认项 |
| 代码修改确认 | 对站点资源的修改会展示差异，确认后再应用 |

## 适合哪些操作

| 场景 | 示例 |
|------|------|
| 当前页面解释 | 询问这个后台页面可以做什么、下一步该点哪里 |
| 配置辅助 | 让 AI 帮你检查 AI 服务、Cookie、Hook、域名等配置顺序 |
| 代码辅助 | 生成或解释 Page、View、Script、Style 的修改建议 |
| 任务延续 | 从会话历史继续上次未完成的站点任务 |

## 与站点 AI 服务的关系

AI 悬浮助手负责交互体验；站点可调用哪些自定义工具、是否禁用内置工具、MCP Endpoint 如何连接，则在 [CMS：AI 服务](/cms/settings/ai-service.md) 中配置。
