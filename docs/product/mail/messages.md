# 邮箱：邮件列表

> 在收件箱、已发送、草稿、垃圾邮件、已删除和自定义文件夹中处理邮件。列表页负责搜索、筛选、标记、移动、删除和进入邮件详情。

## 如何打开

| 项目 | 说明 |
|------|------|
| 菜单路径 | 顶部 **邮箱** -> 左侧 **收件箱 / 已发送 / 草稿 / 垃圾邮件 / 已删除 / 文件夹** |
| 收件箱深链 | `/_Admin/kmail/inbox` |
| 已发送深链 | `/_Admin/kmail/sent` |
| 搜索结果深链 | `/_Admin/kmail/searchEmail?flag=common&keyword={keyword}` |
| 前端路由 | `/kmail/inbox`、`/kmail/sent`、`/kmail/draft`、`/kmail/spam`、`/kmail/trash`、`/kmail/folder`、`/kmail/searchEmail` |

## 左侧菜单

| 区域 | 说明 |
|------|------|
| `写邮件` | 进入撰写页，保留当前地址或返回目录信息 |
| 收件箱 | 展示总未读数；展开后可按邮箱地址筛选 |
| 已发送 | 展示已发送地址分组；展开后可按地址筛选 |
| 文件夹 | 有自定义文件夹时显示，可创建、展开、重命名或删除文件夹 |
| 草稿 / 垃圾邮件 / 已删除 | 固定系统目录 |
| Calendar | 左侧底部固定入口，进入邮箱日历 |
| Settings | 左侧底部固定入口，进入邮箱设置并默认打开邮箱地址页 |

点击当前已激活菜单时，页面会刷新列表和未读数。进入邮箱页后，顶部邮箱红点会被清除。

## 列表工具栏

| 控件 | 说明 |
|------|------|
| 刷新 | 重新加载当前目录邮件，并刷新对应未读数 |
| 搜索框 | 输入关键字并回车，进入搜索结果页 |
| 全选下拉 | 可选择全部、已读、未读 |
| 删除 | 非 Trash 目录会移动到已删除；Trash 中会永久删除 |
| `Mark as` | 批量标记为已读或未读 |
| `Move to` | 批量移动到收件箱、已发送、垃圾邮件或自定义文件夹 |
| `Restore to` | 在已删除目录中用于恢复到其它目录 |
| `Not spam` | 在垃圾邮件目录中将选中邮件移回收件箱 |

列表支持滚动加载更多邮件。若当前目录只剩少量邮件，移动或删除后会自动补拉下一批。

## 邮件行

| 区域 | 说明 |
|------|------|
| 选择框 | 勾选后可批量操作 |
| 已读图标 | 点击可在已读 / 未读之间切换 |
| 发件人 / 收件人 | 收件箱显示发件人；已发送和草稿显示收件人 |
| 主题 | 空主题显示为“无主题”；有附件时显示附件图标和最多 3 个附件名 |
| 时间 | 显示邮件时间 |
| 投递状态 | 已发送邮件可能显示投递状态图标，点击可查看投递日志 |

点击邮件主体区域会进入详情页。未读邮件打开详情时会自动标记为已读。

## 邮件详情

详情页深链：

```text
/_Admin/kmail/content?folder={folder}&messageId={messageId}
```

详情页顶部操作：

| 操作 | 显示条件 | 说明 |
|------|----------|------|
| 返回 | 始终显示 | 返回原目录或搜索结果 |
| 再次编辑 | 已发送、草稿 | 复制当前邮件内容进入撰写页 |
| 回复 / 全部回复 / 转发 | 非草稿 | 带原邮件上下文进入撰写页 |
| 删除 | 始终显示 | 按当前目录规则移入 Trash 或永久删除 |
| 移动 | 非草稿 | 移动到其它系统目录或自定义文件夹 |

详情区可展开收件人详情，查看附件、会议邀请、邮件原文和导出邮件。`显示邮件原文` 会在新标签页打开：

```text
/_Admin/original-message?messageId={messageId}
```

若邮件包含日程邀请，详情页会显示接受、拒绝、暂定和重新选择等操作。

## 文件夹

文件夹只在已有自定义文件夹时显示。点击文件夹标题旁的加号可以新建文件夹；在文件夹项上可重命名或删除。

| 操作 | 说明 |
|------|------|
| 新建 | 填写文件夹名，最长 50 个字符 |
| 重命名 | 修改当前文件夹名；子文件夹路径会随父级变化 |
| 删除 | 有子文件夹时不能直接删除，需先删除子文件夹 |
| 移动邮件 | `Move to` 下拉会包含自定义文件夹树 |

文件夹支持层级路径。界面保存的是完整路径，例如 `Projects/Kooboo`。

## 搜索邮件

右上搜索框输入关键字后回车，会进入搜索结果页。搜索结果行会额外显示邮件所在目录，点击目录名称可跳回对应目录。

前端代码里保留了高级搜索弹窗模型，字段包括关键字位置、发件人、收件人、日期范围、目录和已读状态；但当前高级搜索入口在界面中被注释隐藏。日常操作以右上普通搜索为准。

## 典型工作流

| 场景 | 顺序 |
|------|------|
| 快速处理新邮件 | 收件箱 -> 打开未读邮件 -> 回复或移动 -> 返回列表 |
| 归档项目邮件 | 新建文件夹 -> 勾选邮件 -> `Move to` -> 选择文件夹 |
| 清理垃圾邮件 | 垃圾邮件 -> 勾选误判邮件 -> `Not spam`；其它邮件删除 |
| 追踪已发邮件 | 已发送 -> 查看投递状态 -> 打开投递日志 |
