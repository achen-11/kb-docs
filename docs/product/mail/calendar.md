# 邮箱：日历

> 邮箱日历用于创建日程、邀请参与人，并处理邮件中的会议邀请。创建带参与人的日程时，系统会发送邀请邮件。

## 如何打开

| 项目 | 说明 |
|------|------|
| 菜单路径 | 顶部 **邮箱** -> 左侧底部 **Calendar** |
| 深链 | `/_Admin/kmail/calendar` |
| 前端路由 | `/kmail/calendar` |
| 前置条件 | 建议先在 [邮箱地址](./addresses.md) 中设置默认地址 |

<DocImage src="/product/mail/calendar-overview.png" alt="邮箱日历：月视图与日程列表" width="1120" />

## 页面结构

| 区域 | 说明 |
|------|------|
| 月视图 | 按月展示日程；悬停日期格可点击加号新建日程 |
| 右侧日程列表 | 展示当前选中日期的日程 |
| 日程详情 | 点击右侧日程后弹出详情，可查看时间、地点、说明和参与人状态 |
| 折叠按钮 | 可收起或展开右侧日程列表 |

页面会加载当前日期前后约 31 天的日程。切换月份时会重新加载日程范围。

## 新建日程

在日期格点击加号，或在无日程日期的右侧列表中点击 `New Schedule`，填写：

| 字段 | 填什么 |
|------|--------|
| Schedule Subject | 日程标题，1 到 50 个字符 |
| Participants | 参与人邮箱地址，可为空 |
| Start Time | 开始日期和时间 |
| End Time | 结束日期和时间，必须晚于开始时间 |
| Location | 地点 |
| Description | 富文本说明 |

如果填写了参与人，并且日程尚未过期，保存前会确认是否发送邀请邮件。发送邀请需要默认邮箱地址；没有默认地址时页面会提示先设置默认邮箱。

## 编辑与删除

点击日程后，在详情弹窗底部操作：

| 操作 | 显示条件 | 说明 |
|------|----------|------|
| 编辑 | 当前用户是组织者 | 修改标题、时间、地点、说明和参与人 |
| 删除 | 日程详情中显示 | 删除日程；未过期且有参与人时会确认发送取消邮件 |

编辑未过期日程时，系统会根据变更内容提示是否给原参与人、新增参与人或移除参与人发送邮件。

## 会议邀请

收到带日历信息的邮件时，邮件详情页会显示会议邀请卡片。可选择：

| 操作 | 说明 |
|------|------|
| Yes | 接受邀请 |
| No | 拒绝邀请 |
| Maybe | 暂定接受 |
| Re-select | 已选择后重新选择 |

已过期邀请会显示过期状态，不能继续响应。

## 典型工作流

| 场景 | 顺序 |
|------|------|
| 安排会议 | 设置默认地址 -> Calendar -> 日期格加号 -> 填标题、参与人和时间 -> 保存 |
| 修改会议时间 | Calendar -> 点日程 -> 编辑 -> 修改时间 -> 确认通知参与人 |
| 取消会议 | Calendar -> 点日程 -> 删除 -> 确认发送取消邮件 |
| 处理邀请 | 收件箱 -> 打开邀请邮件 -> Yes / No / Maybe |
