# 邮箱：邮件扩展模块

> 邮件扩展模块用于给邮箱增加自定义处理能力。后台负责创建、导入、安装、启停和配置模块；模块内部代码请在编辑器中维护，脚本 API 细节参考 API 文档。

## 如何打开

| 项目 | 说明 |
|------|------|
| 菜单路径 | 顶部 **邮箱** -> 左侧 **设置** -> **邮件扩展模块** |
| 深链 | `/_Admin/kmail-settings/mail-module` |
| 编辑器深链 | `/_Admin/mail-module-editor?id={moduleId}` |
| 前端路由 | `/kmail-settings/mail-module`、`/mail-module-editor` |
| 可见身份 | 组织管理员 |

## 模块列表

顶部工具栏：

| 按钮 | 说明 |
|------|------|
| `Create` | 新建空模块 |
| `Import` | 上传 zip 包导入模块 |
| `Search` | 从模块市场搜索并安装模块 |

列表区域：

| 列 / 操作 | 说明 |
|-----------|------|
| Name | 点击模块名称进入模块编辑器 |
| Online | 启用或停用模块 |
| Backend | 模块提供后台管理页时显示 `Manage` |
| Settings | 按模块配置定义生成设置表单 |
| Description | 打开模块 `Readme.md` |
| Export | 导出模块包 |
| Share | 分享模块 |
| Delete | 勾选模块后删除 |

## 创建与导入

| 操作 | 填什么 |
|------|--------|
| Create | 模块名称，1 到 50 个字符，需以字母或数字开头 |
| Import | 模块名称 + zip 文件 |
| Search | 输入关键字，点击结果中的 `Install` |

导入失败时页面会显示导入错误。安装搜索结果后，已安装模块会禁用安装按钮。

## 模块设置与说明

点击设置图标后，页面会读取模块根目录的 `module.config`：

| 配置类型 | 后台控件 |
|----------|----------|
| `switch` | 开关 |
| `number` | 数字输入 |
| `select` | 下拉选择 |
| `textarea` | 多行文本 |
| 其它 | 普通输入框 |

点击说明图标会读取 `Readme.md` 并在弹窗中渲染。建议模块作者把安装前提、配置项含义、后台页入口写在说明中。

## 模块编辑器

点击模块名称进入编辑器。

<DocImage src="/product/mail/mail-module-editor.png" alt="邮件扩展模块编辑器" width="1120" />

编辑器左侧按后端返回的资源类型分组，常见分组包括根文件、脚本、样式、视图、后台页、API、图片或其它二进制资源。文本文件使用 Monaco 编辑器；图片和二进制文件可上传。

| 操作 | 说明 |
|------|------|
| 新建文件 | 在支持文本资源的分组上点击加号，填写文件名 |
| 上传文件 | 在图片或二进制分组上选择本地文件 |
| 打开文件 | 点击文件名打开 Tab |
| 保存 | 文件内容变化后，Tab 工具栏显示保存按钮 |
| 刷新 | 重新读取当前文件内容 |
| 预览 | 非根文件可打开预览 URL |
| 离开提示 | 有未保存 Tab 时，离开编辑器会确认 |

## Backend 管理页

如果模块返回 `backendViewUrl`，列表会显示 `Manage` 按钮。点击后在弹窗 iframe 中打开模块自己的后台管理页。这里适合放模块运行状态、队列、日志或业务配置。

## 与 API 的关系

| 后台模块管理 | API / 脚本 |
|--------------|------------|
| 创建、导入、安装、启停模块 | 模块内部调用 [k.mail](/api/mail/) 处理邮件 |
| 配置 `module.config` 的设置项 | 在模块脚本中读取配置 |
| 编辑模块文件 | KScript 语法与对象请看 [API 文档](/api/) 与 [模板引擎](/templateEngine/) |
