# 充值与账单

> 查看账户余额、充值、订单、续费、会员和带宽相关费用入口。

## 如何打开

| 项目 | 说明 |
|------|------|
| 顶部入口 | 组织管理员点击顶部 **充值** 图标 |
| 余额深链 | `/_Admin/kconsole/balance` |
| 订单深链 | `/_Admin/kconsole/consoleOrder` |
| 续费深链 | `/_Admin/kconsole/renew` |
| 带宽充值 | `/_Admin/kconsole/topupBandwidth` |

顶部充值面板会显示当前余额、可能到期的域名、会员计划，以及 **管理所有续费内容** 入口。

## 主要页面

| 页面 | 用途 |
|------|------|
| 余额 | 查看账户余额并充值 |
| 订单 | 查看订单记录，进入订单检查页 |
| 续费 | 统一管理域名、会员等到期项目 |
| 会员 | 查看会员计划并续费 |
| 带宽中心 | 查看带宽或进入带宽充值 |

## 常见工作流

| 场景 | 顺序 |
|------|------|
| 给账户充值 | 顶部充值 -> 余额 -> 选择金额 -> 支付 |
| 核对费用 | 控制台 -> 订单 -> 查看订单状态 |
| 续费域名 | 顶部充值面板 -> 域名服务 -> 域名续费 |
| 续费会员 | 顶部充值面板 -> 会员计划 -> 会员页续费 |
| AI 使用前准备 | 余额 -> 控制台 AI 配置 -> 站点 [AI 服务](/cms/settings/ai-service.md) |

## 与控制台的关系

充值面板是快捷入口，控制台是完整管理页：

| 快捷面板 | 控制台 |
|----------|--------|
| 快速查看余额、到期域名、会员状态 | 查看余额、订单、续费、会员、带宽等完整页面 |
| 适合临时充值或续费提醒 | 适合账务核对、组织管理与服务配置 |
