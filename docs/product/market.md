# 市场

> 从模板市场选择站点起点，查看模板详情，或管理自己分享的模板。

## 如何打开

| 项目 | 说明 |
|------|------|
| 顶部入口 | 点击顶部导航的 **市场** 图标 |
| 模板列表 | `/_Admin/templates` |
| 模板详情 | `/_Admin/template/detail?templateId={模板Id}` |
| 我的分享 | `/_Admin/template/my-shared` |
| 页面层级 | 账户级页面，通常不带 `SiteId` |

市场用于“先选一个可用起点，再创建站点”。模板被使用后会生成普通 Kooboo 站点，后续页面、内容、样式、脚本仍回到站点后台维护。

## 模板列表

进入市场后，顶部工具栏从左到右依次是：

| 控件 | 用法 |
|------|------|
| **模板名称** 搜索框 | 输入关键字后自动搜索。前端会去掉空格再提交查询，适合按模板名快速过滤 |
| 类型下拉框 | 来自模板类型接口；切换后刷新列表 |
| **主题** 下拉框 | 仅在类型为全部或站点模板时显示，多选后会在列表上方生成筛选标签 |
| **颜色** 下拉框 | 仅在类型为全部或站点模板时显示，多选颜色后刷新列表 |
| **我分享的** | 打开自己的模板分享列表 |

列表主体按卡片展示模板。卡片显示模板封面、模板名和下载次数；点击卡片进入模板详情。筛选后，列表上方会显示已选主题或颜色，点击标签右侧关闭图标可移除单个条件，点击 **清除全部** 可重置筛选。

如果没有匹配模板，页面会显示空状态。此时先清除筛选条件，或换一个更短的关键字再试。

## 查看模板详情并创建站点

点击模板卡片进入详情页。详情页顶部同时承担“预览模板”和“用模板创建站点”的操作。

<DocImage src="/product/market/template-detail.png" alt="模板详情：站点名称、域名选择、创建按钮与模板预览" width="1120" />

| 区域 | 填写或检查什么 |
|------|----------------|
| 返回按钮 | 回到模板列表，并保留从站点文件夹进入市场时的 `currentFolder` 查询参数 |
| **站点名** | 新站点的后台名称；必填，长度 1-50，只能使用简单名称规则，且不能与已有站点重名 |
| **域名** 输入框 | 新站点的子域名前缀；必填，长度 1-63，需要满足子域名格式并且域名绑定不能重复 |
| 根域名下拉框 | 选择当前账户可用的根域名；有些根域名使用 `-root` 形式，有些使用 `.root` 形式，以界面显示为准 |
| **创建** | 校验通过后调用模板创建站点；如果从站点文件夹进入市场，创建后会把新站点放回该文件夹 |

详情页中部是预览区。部分模板直接展示截图；如果模板提供在线预览，则会以 iframe 展示，并可在桌面、平板、手机尺寸之间切换。预览下方展示作者、分类、大小、下载次数、最后修改时间，以及模板包含的布局、菜单、页面、视图、图片、内容数量。

创建完成后页面会回到站点列表。接下来通常点击新站点的 **管理**，进入 `/_Admin/site?SiteId={站点GUID}` 继续改页面、内容和设置。

## 我的分享

在模板列表点击 **我分享的**，进入自己的模板管理页。

<DocImage src="/product/market/my-shared.png" alt="我的分享：已分享模板列表与分享按钮" width="1120" />

| 操作 | 说明 |
|------|------|
| **分享** | 打开分享模板弹窗，新增一个分享模板 |
| 模板卡片预览 | 点击眼睛图标打开模板预览地址 |
| **编辑** | 修改模板名称、价格、封面、截图，也可以补充中文名称、中文封面和中文截图 |
| **更新** | 更新模板包本身；可从现有 Kooboo 站点重新生成，也可以上传 ZIP 包 |
| 更多操作 → **删除** | 删除自己分享的模板；删除前会弹确认 |

如果列表为空，说明当前账号还没有分享模板。先点击 **分享** 新建，或切换到拥有模板的账号再查看。

## 分享模板

分享弹窗分为“新增分享”和“更新模板包”两种状态：在 **我的分享** 页点击 **分享** 是新增；在某个模板卡片上点击 **更新** 是更新包。

<DocImage src="/product/market/share-template-dialog.png" alt="分享模板弹窗：模板名称、分享方式、站点或 ZIP 包、封面截图" width="1120" />

新增分享时需要填写：

| 字段 | 说明 |
|------|------|
| **模板名称** | 市场中展示的名称；必填 |
| **分类** | 从模板类型下拉框选择 |
| **价格** | 当前界面以 `CNY` 展示；不收费可填 `0` |
| **分享方式** | 选择 **从 Kooboo 中选择** 或 **上传 ZIP** |
| **站点** | 分享方式为 Kooboo 站点时必选；选择后会自动读取站点封面作为封面和截图初始值 |
| **文件** | 分享方式为 ZIP 时上传 `.zip` 包 |
| **封面 / 截图** | 可保留自动生成图，也可悬停图片后点击更换 |
| **添加中文** | 补充中文模板名称、中文封面和中文截图，用于中文市场展示 |

更新模板包时，弹窗标题为“更新模板包”，只处理模板内容来源：选择 Kooboo 站点或上传 ZIP 包。模板名称、价格、封面、截图等展示信息请用 **编辑** 操作维护。

## 编辑模板信息

在模板卡片上点击 **编辑**，可以维护模板展示信息。

| 字段 | 说明 |
|------|------|
| **模板名称** | 市场列表和详情页展示的名称；必填 |
| **价格** | 模板价格，当前界面显示为 `CNY` |
| **封面** | 模板卡片使用的缩略图 |
| **截图** | 模板详情页可能展示的长截图 |
| **添加中文** | 补充中文名称、中文封面、中文截图；启用后中文名称必填 |

## 什么时候用市场

| 场景 | 建议 |
|------|------|
| 想快速体验 Kooboo | 先从模板创建站点，再按 [快速开始](/quick-start/) 调整 |
| 想复用行业页面结构 | 选择接近业务的模板，进入站点后改页面、内容、样式和脚本 |
| 想沉淀团队模板 | 将成熟站点整理好封面、截图和示例内容，再分享到市场 |
| 想更新已发布模板 | 在 **我的分享** 中用 **更新** 替换模板包，用 **编辑** 调整展示信息 |

## 与 CMS 的关系

| 市场做什么 | CMS 做什么 |
|------------|-------------|
| 选择模板、预览模板、创建新站点 | 维护新站点的页面、内容、菜单、样式、脚本 |
| 分享一个站点或 ZIP 包为模板 | 在分享前清理测试数据、整理页面和媒体资源 |
| 维护模板封面、截图、价格和多语言展示 | 继续在站点后台维护实际业务功能 |

## 典型工作流

| 目标 | 操作 |
|------|------|
| 用模板创建站点 | 市场 → 搜索或筛选模板 → 打开详情 → 填站点名、子域名、根域名 → **创建** |
| 分享现有站点 | 先在 CMS 清理测试内容 → 市场 → **我分享的** → **分享** → 选择站点 → 检查封面和截图 → **分享** |
| 更新模板包 | **我分享的** → 模板卡片 **更新** → 选择站点或上传 ZIP → 确认 |
| 优化模板展示 | **我分享的** → 模板卡片 **编辑** → 调整名称、价格、封面、截图和中文资料 |
