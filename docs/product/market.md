# 市场

> 从模板市场选择站点起点，查看模板详情，或管理自己分享的模板。

## 如何打开

| 项目 | 说明 |
|------|------|
| 顶部入口 | 点击顶部导航的 **市场** 图标 |
| 模板列表 | `/_Admin/templates` |
| 模板详情 | `/_Admin/template/detail` |
| 我的分享 | `/_Admin/template/my-shared` |

## 页面说明

| 页面 | 用途 |
|------|------|
| 模板列表 | 浏览可用模板，作为新建站点的起点 |
| 模板详情 | 查看模板信息、预览效果、进入创建流程 |
| 我的分享 | 管理自己分享到市场的模板 |

## 什么时候用市场

| 场景 | 建议 |
|------|------|
| 想快速体验 Kooboo | 先从模板创建站点，再按 [快速开始](/quick-start/) 调整 |
| 想复用行业页面结构 | 选择接近业务的模板，进入站点后改页面和内容 |
| 想沉淀团队模板 | 将成熟站点整理后分享为模板，再从 **我的分享** 管理 |

## 与 CMS 的关系

模板创建站点后，后续维护仍然回到后台 CMS：

| 模板带来 | 后续维护 |
|----------|----------|
| 页面、布局、视图、样式、脚本 | [页面](/cms/site/pages.md)、[开发](/cms/development/) |
| 示例内容或媒体 | [内容](/cms/content/)、[媒体库](/cms/site/media.md) |
| 站点基础配置 | [站点设置](/cms/settings/) |
