# 邮箱：邮箱地址

> 邮箱地址页决定账户能用哪些地址收发邮件，以及默认发件地址、签名、群组成员和转发目标。首次配置邮箱时，应先完成这一页。

## 如何打开

| 项目 | 说明 |
|------|------|
| 菜单路径 | 顶部 **邮箱** -> 左侧 **设置** -> **邮箱地址** |
| 深链 | `/_Admin/kmail-settings/addresses` |
| 前端路由 | `/kmail-settings/addresses` |
| 前置条件 | 域名需出现在当前组织的域名列表中；在线服务环境提示邮箱面向使用 Kooboo DNS 的域名开放 |

## 顶部工具栏

| 控件 | 说明 |
|------|------|
| `New Address` | 下拉创建普通地址、通配地址、群组、转发地址 |
| 默认地址 | 从非通配地址中选择默认发件地址 |

修改默认地址前会出现确认提示。默认地址会影响撰写页默认发件人、IMAP 授权码生成和日历邀请发送。

## 地址类型

| 类型 | 适合场景 | 创建时填写 |
|------|----------|------------|
| 普通地址 | 个人或业务固定邮箱，例如 `support@example.com` | 名称、地址前缀、域名 |
| 通配地址 | 接收同域名下未单独创建的地址 | 名称、通配地址、域名 |
| 群组 | 一个地址分发给多个成员 | 名称、群组地址、域名；保存后维护成员 |
| 转发地址 | 收到邮件后转发到外部邮箱 | 名称、代理地址、域名、转发地址 |

创建地址时，左侧输入地址前缀，右侧从域名下拉中选择 `@domain`。编辑已有地址时，地址和域名不可改，只能改名称；转发地址还可以更新转发目标。

## 地址列表

| 列 / 操作 | 说明 |
|-----------|------|
| Address | 完整邮箱地址 |
| Name | 显示名称 |
| Use For | 地址类型标签 |
| Remark | 转发地址显示转发目标；群组显示成员数量 |
| 编辑签名 | 非通配地址可维护签名 |
| 编辑 | 修改名称，转发地址可修改转发目标 |
| 进入收件箱 | 跳到收件箱并按该地址筛选 |
| 删除 | 勾选一条或多条地址后删除 |

删除默认地址后，页面会清空默认地址，需要重新选择。

## 群组成员

点击群组地址的成员标签，会打开群组成员弹窗。

| 操作 | 说明 |
|------|------|
| 添加成员 | 点击加号，输入成员邮箱并保存 |
| 移除成员 | 点击成员行的 `Remove` |
| 校验 | 成员地址必须是有效邮箱，长度需符合校验规则 |

群组适合 `team@example.com`、`support@example.com` 这类需要多人接收的地址。

## 签名

点击地址行的签名图标打开签名编辑器。签名使用富文本编辑器维护，保存后会在撰写页按发件人自动插入。

| 场景 | 说明 |
|------|------|
| 新邮件 | 签名插入正文末尾 |
| 回复 / 转发 | 签名插入原邮件内容之前 |
| 多个发件地址 | 每个地址维护自己的签名 |

## 典型工作流

| 场景 | 顺序 |
|------|------|
| 首次开通发信 | 确认域名 DNS -> 新建普通地址 -> 设置默认地址 -> 写一封测试邮件 |
| 做客服组邮箱 | 新建群组 -> 添加成员 -> 进入收件箱检查收件 |
| 转发到外部系统 | 新建转发地址 -> 填转发目标 -> 发送测试邮件 |
| 准备外部客户端 | 设置默认地址 -> [IMAP](./imap.md) -> 生成授权码 |
