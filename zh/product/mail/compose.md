# 邮箱：撰写邮件

> 撰写页用于新建邮件、回复、全部回复、转发、再次编辑和继续编辑草稿。页面会自动保存草稿，并在离开时提示未保存改动。

## 如何打开

| 项目 | 说明 |
|------|------|
| 菜单路径 | 顶部 **邮箱** -> 左侧 **写邮件** |
| 深链 | `/_Admin/kmail/compose` |
| 前端路由 | `/kmail/compose` |
| 进入方式 | 新建、草稿、回复、全部回复、转发、再次编辑 |

如果进入撰写页时没有可用发件地址，页面会提示先添加邮箱地址。建议先完成 [邮箱地址](./addresses.md)，并设置默认地址。

## 表单字段

| 字段 | 填什么 |
|------|--------|
| 发件人 | 从当前账号可用邮箱地址中选择；默认取默认地址或第一个地址 |
| 收件人 | 输入一个或多个邮箱地址 |
| 抄送 / 密送 | 点击 `Add Cc` / `Add Bcc` 后显示，可删除 |
| 主题 | 必填；空主题不能发送 |
| 附件 | 点击 `Select` 上传文件 |
| 内容 | 使用富文本编辑器编写正文 |

收件人、抄送和密送使用同一套邮箱校验。已输入的地址标签支持在 `To`、`Cc`、`Bcc` 之间拖动。

## 附件

| 规则 | 说明 |
|------|------|
| 单次选择 | 每次选择一个文件 |
| 总大小 | 当前邮件全部附件合计不能超过 20 MB |
| 删除附件 | 点击附件标签上的关闭按钮 |
| 发送前上传 | 选择文件后会先上传附件，邮件正文只引用上传后的附件信息 |

## 底部按钮

| 按钮 | 说明 |
|------|------|
| `Send` | 校验表单并发送邮件 |
| `Save Draft` | 手动保存草稿 |
| `Cancel` | 取消当前编辑；若有改动会出现离开确认 |

页面每 20 秒检查一次内容变化并自动保存草稿。自动保存过程中，发送按钮会显示“草稿保存中”并暂时不可点击。

## 签名

切换发件人时，撰写页会读取该地址的签名并插入正文。签名在 [邮箱地址](./addresses.md#签名) 中维护。

| 场景 | 插入位置 |
|------|----------|
| 新邮件 | 正文末尾 |
| 回复 / 转发 / 全部回复 | 原邮件内容之前 |
| 发件人切换 | 重新读取对应地址签名 |

## 回复、转发和再次编辑

从邮件详情进入撰写页时，路由会带上 `sourceId` 和 `type`：

| 类型 | 说明 |
|------|------|
| `Reply` | 回复发件人 |
| `ReplyAll` | 回复所有相关收件人 |
| `Forward` | 转发当前邮件 |
| `Drafts` | 继续编辑草稿 |
| `EditAgain` | 基于已发送邮件再次编辑 |

这些入口会预填发件人、收件人、主题、正文和附件上下文。保存后的草稿会更新当前草稿 ID。

## 扩展抽屉

撰写页右侧可能出现邮件扩展抽屉。它来自已启用的邮件扩展模块，用于在写信时提供额外动作或上下文。如何开发模块请从 [邮件扩展模块](./modules.md) 进入，脚本 API 细节看 [k.mail](/api/mail/)。

## 典型工作流

| 场景 | 顺序 |
|------|------|
| 发送新邮件 | 写邮件 -> 选择发件人 -> 填收件人和主题 -> 写正文 -> 发送 |
| 加附件发送 | 写邮件 -> 选择附件 -> 等附件标签出现 -> 发送 |
| 继续草稿 | 草稿 -> 打开邮件 -> 修改内容 -> 发送或保存 |
| 复用已发邮件 | 已发送 -> 打开详情 -> 再次编辑 -> 修改收件人与正文 -> 发送 |
