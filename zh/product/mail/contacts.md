# 邮箱：联系人

> 联系人页维护常用联系人，便于日常写信和实施人员统一整理收件人地址。

## 如何打开

| 项目 | 说明 |
|------|------|
| 菜单路径 | 顶部 **邮箱** -> 左侧 **设置** -> **联系人** |
| 深链 | `/_Admin/kmail-settings/contacts` |
| 前端路由 | `/kmail-settings/contacts` |

<DocImage src="/product/mail/contacts-overview.png" alt="邮箱联系人列表" width="1120" />

## 联系人列表

| 区域 | 说明 |
|------|------|
| `Add Contact` | 新增联系人 |
| Name | 联系人名称 |
| Address | 联系人邮箱地址 |
| 编辑 | 修改联系人名称或邮箱 |
| 删除 | 勾选联系人后批量删除 |

列表按名称升序排序。删除前会出现确认提示。

## 新增或编辑联系人

点击 `Add Contact` 或编辑图标后填写：

| 字段 | 规则 |
|------|------|
| Name | 必填，1 到 64 个字符 |
| Address | 必填，必须是有效邮箱地址 |

新增时会校验邮箱地址是否已存在；编辑已有联系人时允许保留原地址。

## 典型工作流

| 场景 | 顺序 |
|------|------|
| 维护常用收件人 | 联系人 -> Add Contact -> 填名称和邮箱 -> 保存 |
| 修正错误邮箱 | 联系人 -> 编辑 -> 修改 Address -> 保存 |
| 清理无效联系人 | 勾选联系人 -> 删除 -> 确认 |
