# AI 悬浮助手

> 站点后台右下角的全局 AI 浮窗，基于当前后台页面上下文提供建议、对话、工具调用和操作确认，并支持自由移动与缩放。

## 出现位置

AI 悬浮助手挂载在站点后台布局中。进入站点后台后，在右下角可以看到 AI 浮动按钮。

| 项目 | 说明 |
|------|------|
| 入口 | 右下角 **AI** 浮动按钮 |
| 层级 | 站点级上下文 |
| 常见页面 | CMS 站点后台、开发菜单、开发者模式、站点级空白布局页面 |
| 不一定显示 | 控制台、市场、邮箱等账户级页面，或受限站点环境 |

悬浮助手不会替代当前页面。它保留你正在操作的后台页面，在右下角打开一个可收起、可移动、可缩放的 AI 面板。

<DocImage src="/product/ai-floating-assistant/floating-button.png" alt="站点后台页面右下角的 AI 悬浮按钮" width="1120" />

## 上下文来源

悬浮助手打开时，会把当前站点和当前页面作为对话上下文的一部分。

| 上下文 | 来源 |
|--------|------|
| 当前站点 | URL 中的 `SiteId` |
| 当前页面 | 当前路由和路由标题，例如“页面”“内容”“站点设置” |
| 会话历史 | 当前站点下的 AI 会话 |
| 当前资源引用 | 开发者模式或代码编辑器中手动添加的代码引用 |
| 可调用能力 | [CMS：AI 服务](/cms/settings/ai-service.md) 中启用的 MCP、AI 函数和内置工具 |

面板顶部的 **当前页面** Banner 用来确认 AI 正在基于哪个后台页面理解问题。如果你从页面列表切到站点设置，再打开悬浮助手，Banner 也会随路由变化。

## 展开和调整浮窗

点击右下角按钮后，浮窗会在当前页面上方展开。

<DocImage src="/product/ai-floating-assistant/floating-panel.png" alt="AI 悬浮助手展开状态：可移动和缩放的对话浮窗" width="1120" />

| 区域 | 怎么用 |
|------|--------|
| 标题栏 | 查看 Kooboo AI；拖动按钮之外的空白区域可以移动浮窗 |
| 当前页面 Banner | 确认当前上下文来自哪个后台页面 |
| 消息区 | 查看 AI 回复、工具调用、思考过程、复制内容 |
| 输入区 | 输入问题，选择模型，上传图片，切换执行策略 |
| 发送按钮 | 点击发送，或使用 `Ctrl + Enter` |

未展开时，如果当前页面有推荐操作，按钮上方可能显示“我可以”快捷建议。点击建议会直接打开面板并把对应操作带入当前会话。

### 移动和缩放

| 操作 | 方法 |
|------|------|
| 移动浮窗 | 按住标题栏中不属于按钮、输入框或链接的空白区域拖动 |
| 调整宽度或高度 | 拖动浮窗任意一条边 |
| 同时调整宽高 | 拖动四个角；右下角和左下角会显示尺寸调整提示 |
| 临时放大 | 点击标题栏 **全屏**；按 `Esc` 或再次点击全屏按钮恢复 |

浮窗最小尺寸为 `360 × 420` 像素，不能拖出可视区域，也不会越过后台顶部栏。浏览器窗口大小发生变化时，浮窗会自动收回可视范围。

浮窗的位置和尺寸保存在当前浏览器中。收起后再次打开，或刷新后台页面时，会恢复上次使用的浮窗布局；全屏状态不作为长期布局保存。

## 标题栏按钮

| 按钮 | 说明 |
|------|------|
| **+** | 新建会话 |
| 历史 | 打开最近会话，切回之前的对话 |
| 全屏 | 把浮窗扩展为全屏对话视图；适合阅读长回复或审阅修改 |
| 关闭 | 收起面板，回到右下角按钮 |

## 输入区

| 控件 | 说明 |
|------|------|
| 模型选择 | 选择当前对话使用的 Provider 和模型；如果没有可选模型，先检查 [控制台：AI 配置](./console/ai-config.md) |
| 执行策略 | 快捷切换 **每次确认**、**仅自动执行允许项**、**自动执行**；完整配置见 [AI Claw 设置](./ai-chat.md#设置) |
| 上传图片 | 添加截图或图片作为上下文 |
| Token 使用量 | 当界面显示使用量按钮时，可查看上下文窗口占用情况 |
| 发送 / 停止 | 未生成时发送消息，生成中则停止当前回答 |

输入区支持编辑上一条用户消息、排队消息、停止后继续输入等交互。普通配置问题可以直接问；涉及写入、删除、代码修改或工具调用时，要先看清确认内容再执行。

## 和开发者模式配合

开发者模式中的资源标签和代码编辑器可以把当前文件加入 AI 对话引用。

| 场景 | 操作 |
|------|------|
| 解释当前代码 | 开发者模式打开资源 -> 右键标签 -> **添加到对话** -> 打开悬浮助手提问 |
| 修改页面或脚本 | 先让 AI 说明修改思路 -> 查看代码差异 -> 确认后应用 |
| 排查 API 或 CodeBlock | 在开发者模式调试资源 -> 把代码加入引用 -> 让 AI 基于代码上下文分析 |

这里说明的是后台交互入口。KScript、模板资源和 API 的具体写法，请看 [API](/api/) 与 [模板引擎](/templateEngine/)。

## 与 AI Claw 的区别

| AI 悬浮助手 | AI Claw / AI Chat |
|-------------|-------------------|
| 贴着当前后台页面使用 | 独立 AI 工作台：对话 + 左侧面板 + 右侧站点工作区 |
| 适合边配置边提问、快速解释当前页面 | 适合建站预览、看代码、跑固定任务、查任务日志和人工帮助 |
| 入口是右下角浮动按钮 | 入口是顶部 **AI** 按钮 |

## 常用工作流

| 目标 | 操作 |
|------|------|
| 问当前页面怎么配置 | 打开目标 CMS 页面 -> 点击右下角 AI -> 直接提问 |
| 让 AI 检查配置顺序 | 保持页面打开 -> 在浮窗中描述目标 -> 按回复检查字段 |
| 边看列表边对话 | 打开浮窗 -> 拖到不遮挡列表的位置 -> 从边缘调整合适尺寸 |
| 处理长回复 | 打开浮窗 -> 点击全屏 -> 阅读或复制内容；按 `Esc` 恢复 |
| 回到完整 AI 工作台 | 顶部 **AI** -> 进入 [AI Claw / AI Chat](./ai-chat.md) |
