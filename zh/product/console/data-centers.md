# 控制台：数据中心

> 管理当前组织可用的数据中心，决定默认数据中心，并可跳转到目标数据中心后台。

## 如何打开

| 项目 | 说明 |
|------|------|
| 菜单路径 | 顶部 **控制台** -> 左侧 **数据中心** |
| 深链 | `/_Admin/kconsole/serviceDataCenter` |
| 前端路由 | `/kconsole/serviceDataCenter` |
| 可见身份 | 组织管理员 |

数据中心页是组织级管理入口。它不同于域名列表中的“更换某个域名的数据中心”；这里管理的是组织可用的数据中心列表和默认项。

## 页面结构

数据中心页是单选表格。先选择一行，再使用表格上方操作按钮。

| 区域 | 说明 |
|------|------|
| `Enable` | 对未启用的数据中心可用，确认后启用 |
| `Disable` | 对已启用的数据中心可用，确认后禁用 |
| `Set as Default` | 对已启用的数据中心可用，设置为默认数据中心 |
| 表格单选 | 默认数据中心不可选为待操作项 |

表格列：

| 列 | 说明 |
|----|------|
| Name | 数据中心名称 |
| Description | 数据中心说明 |
| Enable Status | 是否启用 |
| Default | 是否为默认数据中心 |
| Go To | 跳转到该数据中心后台 |

## 启用与禁用

| 操作 | 适合场景 | 注意 |
|------|----------|------|
| 启用 | 组织需要开始使用某个数据中心 | 启用前会弹确认 |
| 禁用 | 组织不再使用某个数据中心 | 禁用前会弹确认 |
| 设为默认 | 新站点或默认服务希望优先落到某个数据中心 | 只能对已启用的数据中心操作 |

默认数据中心会影响后续部分组织级服务的默认落点。已有域名的数据中心调整，请在 [域名](./domains.md#续费-转移码与数据中心) 页针对具体域名处理。

## 跳转到数据中心

表格最右侧的 `Go To` 图标用于打开目标数据中心后台。

| 状态 | 行为 |
|------|------|
| 已启用 | 使用当前登录 token 拼接 `auto_login=true`，在新标签页打开目标数据中心 |
| 未启用 | 图标不可用 |

如果跳转后无法自动进入，通常先检查当前登录状态、组织权限，以及目标数据中心是否已启用。

## 常见工作流

| 场景 | 顺序 |
|------|------|
| 组织首次启用新数据中心 | 选择数据中心 -> Enable -> Set as Default |
| 临时进入某个数据中心排查 | 确认已启用 -> Go To |
| 域名需要迁移数据中心 | 先确认组织数据中心可用 -> 回 [域名](./domains.md) 点击数据中心列调整 |
