# 控制台：余额

> 查看当前组织余额、最近收支记录，并从余额页发起充值订单。

## 如何打开

| 项目 | 说明 |
|------|------|
| 菜单路径 | 顶部 **控制台** -> 左侧 **余额** |
| 深链 | `/_Admin/kconsole/balance` |
| 前端路由 | `/kconsole/balance` |
| 可见身份 | 组织管理员 |

余额属于当前组织。切换组织后，余额、最近收支和订单都会变成另一个组织的数据。

## 当前余额

余额页表格顶部显示：

| 区域 | 说明 |
|------|------|
| Current Balance | 当前余额金额 |
| Currency | 余额币种 |
| Recharge | 打开充值弹窗 |

如果你准备购买域名、续费会员或使用在线 AI 能力，建议先在这里确认余额。

## 最近收支记录

表格显示最近收支：

| 列 | 说明 |
|----|------|
| Name | 收支项目名称 |
| Date | 发生时间 |
| Direction | 加款或扣费方向 |
| Amount | 金额 |

`Direction` 使用图标区分收入与支出。排查扣费时，优先按日期和金额定位记录，再到 [订单](./orders.md) 页核对订单状态。

## 充值

点击 `Recharge` 会打开充值弹窗。

| 字段 | 说明 |
|------|------|
| Amount | 充值金额，默认填入 `50` |
| Currency | 当前余额币种，只读展示 |
| Recharge | 校验金额后创建充值订单 |

确认充值后会跳转到：

```text
/_Admin/kconsole/checkOrder?orderId={orderId}
```

后续在 [订单：结账页](./orders.md#结账页) 选择信用卡或微信支付。

## 常见工作流

| 场景 | 顺序 |
|------|------|
| 充值账户 | 余额 -> Recharge -> 填金额 -> 结账页付款 |
| 核对扣费 | 余额 -> 最近收支记录 -> 订单页核对对应订单 |
| AI 使用前准备 | 余额 -> [AI 配置](./ai-config.md) -> [CMS：AI 服务](/cms/settings/ai-service.md) |
| 域名购买前准备 | 余额 -> [域名](./domains.md#购买域名) |

## 与充值面板的关系

顶部导航的充值图标是快捷面板，余额页是完整页面：

| 顶部充值面板 | 余额页 |
|--------------|--------|
| 快速查看余额、域名到期和会员到期 | 查看当前余额和最近收支记录 |
| 适合临时充值或续费提醒 | 适合账务核对 |
