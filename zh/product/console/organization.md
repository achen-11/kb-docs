# 控制台：组织

> 管理当前账户所在组织、成员、部门，以及组织切换。组织是域名、余额、会员和 AI 配置的归属边界。

## 如何打开

| 项目 | 说明 |
|------|------|
| 菜单路径 | 顶部 **控制台** -> 左侧 **组织** |
| 深链 | `/_Admin/kconsole/organization` |
| 前端路由 | `/kconsole/organization` |
| 可见身份 | 所有组织成员可见；成员维护和部门维护需要组织管理员 |

组织页适合先确认“当前正在操作哪个组织”。切换组织后，域名、余额、订单、会员、AI 配置等也会随之变化。

## 页面顶部摘要

顶部会显示三项信息：

| 项目 | 说明 |
|------|------|
| 当前组织 | 当前生效的组织名称 |
| 成员 | 当前组织成员数量 |
| 身份 | 你在当前组织中是管理员还是普通成员 |

右侧两个按钮：

| 按钮 | 说明 |
|------|------|
| `部门` | 进入部门管理页 |
| `管理组织` | 打开组织列表，可切换组织、离开组织或创建自己的组织 |

## 成员列表

成员表展示：

| 列 | 说明 |
|----|------|
| User Name | 用户名；管理员会带 `Admin` 标识 |
| Email | 成员邮箱 |
| Join Date | 加入组织的时间 |

如果你是组织管理员，表格上方会显示：

| 按钮 | 填什么 / 做什么 |
|------|----------------|
| `添加成员` | 输入已有用户名，把该用户加入当前组织 |
| `创建成员` | 新建组织用户，填写用户名、密码、邮箱、电话 |
| `导出` | 导出当前组织成员列表 |

删除成员时，表格会先弹确认框；管理员成员在列表中不可直接勾选删除。

## 添加成员与创建成员

两种入口的区别：

| 入口 | 适合场景 | 表单字段 |
|------|----------|----------|
| 添加成员 | 用户已经存在，只是加入当前组织 | `User Name` |
| 创建成员 | 需要为组织创建一个新账号 | `User Name`、`Password`、`Email`、`Phone` |

创建成员会校验用户名、密码、邮箱与电话格式。成员创建完成后会刷新成员列表。

## 管理组织

点击 `管理组织` 会打开组织列表弹窗。

| 区域 | 说明 |
|------|------|
| 组织列表 | 显示组织名称、成员数，并标记当前组织 |
| `Depart` | 离开选中的组织；如果你是该组织管理员，该按钮会禁用 |
| `Create Own Org` | 当你没有任何管理员组织时显示 |
| `Switch` | 切换到选中组织 |

切换组织或离开组织后，前端会退出当前登录态并返回登录页；重新登录后再继续操作。

## 部门

从组织页点击 `部门` 进入：

```text
/_Admin/kconsole/departments
```

<DocImage src="/product/console/organization-departments.png" alt="控制台部门列表" width="1120" />

部门列表显示：

| 列 | 说明 |
|----|------|
| Name | 部门名称 |
| Members | 部门成员数，点击数字可查看部门成员 |

组织管理员可点击 `Add Department` 新建部门，填写 `Name` 即可。部门成员弹窗中可以：

| 操作 | 说明 |
|------|------|
| `Add User` | 从组织成员中选择用户加入部门 |
| Function | 填写该用户在部门中的职能 |
| Is Manager | 设置是否为部门负责人 |
| 删除 | 从部门中移除选中成员 |

## 常见工作流

| 场景 | 顺序 |
|------|------|
| 新组织准备上线 | 管理组织 -> 确认当前组织 -> 添加成员 / 创建成员 -> 部门 |
| 给实施同学开权限 | 创建成员 -> 部门中添加用户 -> 回站点后台配置 [角色权限](/cms/settings/roles.md) |
| 切换到客户组织 | 管理组织 -> 选择组织 -> Switch -> 重新登录 |
| 离开不再维护的组织 | 管理组织 -> 选择组织 -> Depart |

## 与站点用户的区别

| 控制台组织成员 | CMS 站点用户 |
|----------------|--------------|
| 决定用户是否属于某个组织，影响控制台域名、余额、会员、AI 配置等账户级能力 | 决定用户是否能进入某个站点后台，以及能操作哪些站点功能 |
| 深链 `/_Admin/kconsole/organization` | 深链 `/_Admin/system/siteuser?SiteId={GUID}` |
