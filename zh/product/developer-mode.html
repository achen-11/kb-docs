开发者模式 ​

在站点后台中打开类 VS Code 的开发工作台，同时查看、编辑、搜索和调试多个站点资源。

如何打开 ​

项目说明
顶部入口进入站点后台后，点击顶部 开发者模式 图标
深链/_Admin/dev-mode?SiteId={站点GUID}
指定面板/_Admin/dev-mode?SiteId={站点GUID}&activity={面板名}
前端路由/dev-mode
页面层级站点级页面，必须带 SiteId

开发者模式适合连续编辑多个站点资源。它不会替代 CMS 开发菜单：CMS 更适合单个资源的结构化表单和列表管理；开发者模式更适合在页面、布局、视图、脚本、样式、Code 之间来回切换。

权限与可见面板 ​

开发者模式会按当前用户的站点权限显示左侧面板。没有对应权限的面板不会出现在活动栏中。

面板权限来源主要用途
页面pages打开普通页面、富文本页面和设计页面
视图view编辑 View 组件
布局layout编辑 Layout
样式style编辑内联样式、外部样式和样式组
脚本script编辑内联脚本、外部脚本和脚本组
Codecode编辑 API、CodeBlock、PageScript 等代码资源
菜单menu查看和打开菜单资源
表单form编辑表单资源
搜索code跨站点资源搜索代码内容
调试code · debug打开可调试代码并进入调试面板
模块module查看模块资源，或从模块编辑状态返回普通开发者模式
设置site · edit点击左下角齿轮后，以标签页形式打开站点设置

如果用户只有部分资源权限，开发者模式会自动裁剪工作区。排查“为什么看不到某个面板”时，先检查角色权限，而不是路由地址。

工作区结构 ​

开发者模式主要分为三层：

区域怎么用
左侧活动栏点击图标切换资源类型，例如页面、视图、布局、样式、脚本、Code、搜索、调试
资源面板展示当前资源类型的文件树或列表；顶部可用文件名搜索过滤当前面板
标签页和编辑区点击资源后打开标签页；在编辑区修改内容、保存、刷新或预览

左侧面板标题右侧通常有两个常用按钮：

按钮说明
刷新重新加载当前面板的资源列表
更多跳转到对应的 CMS 开发菜单列表页，例如页面列表、布局列表、脚本列表

底部齿轮按钮会打开站点设置标签页。它使用站点级设置组件，适合临时改一些站点基础配置；完整的站点设置操作仍建议回到 CMS：站点设置。

打开、编辑和保存资源 ​

点击资源面板中的文件名，资源会在右侧打开一个标签页。再次点击同一个资源不会重复打开标签，而是切回已有标签。

操作说明
打开资源在左侧资源面板点击文件名
切换标签点击顶部标签页；标签很多时可横向滚动
拖动排序拖动标签页可调整顺序
保存点击标签页右侧的保存按钮，或使用系统绑定的保存快捷键
刷新重新读取当前资源内容；有未保存修改时先确认
预览页面、视图、布局、脚本、样式、API 等支持预览的资源会显示预览按钮
关闭点击标签页关闭图标；未保存时会弹出确认

标签左侧出现小圆点表示当前内容已修改但尚未保存。离开开发者模式、切换站点或批量关闭标签时，如果存在未保存内容，界面会提示确认。

标签页右键菜单 ​

在标签页上点击右键，会打开标签管理菜单。

操作说明
添加代码引用对支持的资源，把当前编辑器内容作为代码引用加入 AI 全局聊天
关闭关闭当前标签
关闭右侧关闭当前标签右侧的所有标签
关闭其他只保留当前标签
关闭已保存关闭所有没有未保存修改的标签
关闭全部关闭所有标签；存在未保存修改时会先确认

“添加代码引用”主要用于让 AI 助手理解当前资源上下文。它不会自动改代码，只是把当前标签内容送到右下角 AI 对话侧边栏中作为引用。

搜索 ​

开发者模式有两种搜索入口，使用场景不同。

搜索方式入口适合什么
当前面板文件名搜索在资源面板中按 Ctrl + F，或点击资源面板顶部搜索框文件很多时快速过滤当前类型的资源名称
全局代码搜索左侧活动栏 搜索 面板在页面、布局、视图、脚本、样式、Code 等资源内容中查找关键字

全局代码搜索面板包含三个关键控件：

控件说明
关键字输入框输入后自动搜索
Aa切换大小写匹配
.*切换正则表达式搜索；正则无效时不会提交搜索

搜索结果按资源分组展示命中行。点击资源名会打开资源并跳到开头；点击某一行命中，会打开资源并跳到对应行。

调试 ​

调试面板只对拥有 code · debug 权限的用户显示。它会按 Code 类型列出可调试资源，点击后打开调试标签页。

区域说明
左侧调试列表按 Code 类型分组，例如 API、CodeBlock、PageScript 等
调试标签页打开当前调试会话，提供刷新和预览按钮
控制台输入调试会话未结束时，可输入代码并回车执行
执行结果控制台会把返回值以文本或 JSON 树展示

这里的文档只说明后台入口和操作方式。具体可调试代码如何编写、上下文变量如何使用，请看 API 和 模板引擎 对应章节。

常用工作流 ​

目标操作
同时调整页面和布局打开 页面 面板 → 打开页面 → 打开 布局 面板 → 打开对应布局 → 来回切换标签保存
修改外部 CSS 或 JS打开 样式 或 脚本 面板 → 找到外部资源 → 修改 → 保存 → 预览
查找某段代码在哪里打开 搜索 面板 → 输入关键字 → 需要精确匹配时打开 Aa 或 .* → 点击命中行
调试 API 或 CodeBlock打开 调试 面板 → 点击代码资源 → 进入调试标签 → 需要时用控制台执行辅助表达式
让 AI 理解当前文件打开资源标签 → 右键标签 → 添加代码引用 → 在 AI 全局聊天继续提问

与 CMS 开发菜单的关系 ​

CMS 开发菜单开发者模式
适合创建、删除、批量管理和查看结构化列表适合打开多个资源连续编辑
每类资源有独立页面和表单页面、视图、布局、脚本、样式、Code 等在同一工作区中切换
文档按菜单逐页说明字段和按钮本页说明统一工作台的使用方式
更适合实施人员按表单配置更适合开发者按文件上下文排查和修改

退出前检查 ​

离开开发者模式前，建议按顺序检查：

  1. 顶部标签页是否还有小圆点。
  2. 需要保存的标签是否已经点过保存。
  3. 预览页面是否已经刷新确认。
  4. 如果要切换站点，先关闭或保存当前站点的标签页。

如果仍有打开的标签，离开时会提示“离开当前网站的开发者模式将关闭所有文件选项卡。确认离开吗？”。
